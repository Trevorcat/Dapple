# 原型审查汇总 · 2026-11-11

来源：5 个并行审查（Apple HIG、Material 3/Android、产品原则与流程、视觉细节、无障碍与交互逻辑），对象 `design/prototype/project/Main.dc.html`（含 Android 变体）与旧版 `Unfolded.dc.html`。下面是去重后的修复清单，以及与产品负责人决策冲突时的裁决。

## 裁决（与审查建议冲突时以此为准）

| 审查建议 | 裁决 |
|---|---|
| 调色盘加可见的「淡/浓/暖/冷」轴标签和数值（HIG A11、视觉 M4） | **不采纳**。负责人明确认为丑陋且居高临下。只保留在 aria 里。 |
| 九宫格去掉行列标题（产品 M1） | **采纳**：去掉行列标题；格内只保留小号专业名（高长调…）放在半透明深色胶囊里；「原片接近」用小圆点标记，不用「原片」二字（与按住对比的「原片」冲突）。 |
| 直方图卡删掉区域条与分位线（视觉 M3） | **不采纳**（负责人喜欢这个样式）。只修几何：不留空白、`vector-effect: non-scaling-stroke`、区域条可见度提高、标注 11px。 |
| Android 发布只走系统 Sharesheet（M3 #19） | **部分采纳**：保留「平台预设」（比例/尺寸），Android 最终动作为「分享…」调起系统分享；iOS 同理用系统分享面板，「存相册再打开 App」作为兜底。 |
| 新到照片放在网格底部（HIG A13） | **改为**：保持最新在前，但在多选/滚动时不重排，顶部出现「新到 N 张」胶囊，点一下再插入。 |

## 统一术语

- **风格**＝色彩风格（色样 + 调色盘 + 风格强度）。编辑器第一个标签仍叫「风格」，内含「明暗」与「风格」两节。
- **明暗**＝调性（九宫格 + 明暗强度）。界面上不再出现「影调/调性/影调策略」。
- 「颜色」标签内的 tint 改叫 **色偏**。「分级」在标签和入口统一叫 **分级**。
- **处理**取代「冲洗/校正」（处理中 / 已处理 / 自动处理）。
- 实况：iOS 只说 **实况照片**，Android 只说 **动态照片**，不在同一平台混写。
- 「原片」只用于对比原图；裁切比例「原始」改为「原比例」。

## P0 · 必须修

1. **编辑面板**改为可拖动的底部面板（抓手 + 两档：约 45% / 约 75% 屏高），去掉底部操作行：
   - 顶栏：返回 · 标题 · 撤销 / 重做 · 「···」菜单 · **完成**（主按钮，或 iOS 文本按钮）。
   - 「···」菜单：复制设置、粘贴设置、同步设置…、还原为自动结果（需确认）。
   - 照片区加可见的「对比」开关（44pt），保留按住对比；左右切换上一张/下一张。
   - 顶栏加「分享」，可直接发布当前这张。
2. **撤销**：还原、粘贴、同步、改默认风格都给带「撤销」的提示（有操作时 8 秒）；编辑器有多级撤销/重做。
3. **同步设置**取代「用到本组」：弹出勾选项（风格 / 明暗 / 光线 / 颜色 / 效果与细节；裁切默认不勾），作用于多选的照片或本组，**合并而不是覆盖**，显示「已同步 N 张」。
4. **复制/粘贴**覆盖全部状态（风格、风格强度、调色盘、明暗目标、明暗强度、全部滑杆），不带裁切几何；可多次粘贴。
5. **滚动容器塌缩**：`.vs > * { flex-shrink: 0 }`（风格页、设置页、工具页内容被压扁的根因）。
6. **照片比例**：舞台用 container query 计算宽高，横图不再被压成近方形。
7. **提示条位置**：按屏幕计算 bottom，不压住主按钮；Android Snackbar 带「撤销」动作，颜色走 token（深色模式反色）。
8. **HDR/全景**：
   - 基准帧改为点缩略图标星（不再出现一排「RAW RAW RAW」），标签用曝光值或序号。
   - 识别说明只在确实是自动识别的那组时显示；从首页多选进入时说「已带入你选的 N 张」。
   - 已取消勾选的照片仍留在候选里可以再勾回。
   - 来源按拍摄时间排序。
   - 选片弹窗的「取消」要恢复打开前的选择；弹窗只列已处理完成的照片。
   - 后台任务记住自己的类型，完成时不强行跳页；任务弹窗可「取消」，进度条有 progressbar 语义。
9. **合成结果与「昨天」网格**可以被选择、可以打开编辑、可以发布。
10. **失败与空状态**（加一个 Tweak「演示状态」切换）：相机断开（卡片显示「已断开 · 重新连接」）、传输中断（单张琥珀色标记 + 重试）、相册为空、合成失败（「没能对齐这几张 · 换基准帧 / 取消」）。
11. **Android 包装器**布尔属性按字符串处理（`'false'` 不能当真），否则深色/引导开关失效。

## P1 · 应该修

- **文案**：删掉所有说明句和「第一步」「点照片来选择」「（对齐与去鬼影以它为准）」「输出：16 位线性 RAW…」「中性灰背景 · 轻点退出」等；「通过 FTP 接收 RAW」→「无线接收 RAW」；任务步骤简化为「对齐 → 合并 → 处理」；完成页三步如实：✓ 已存入相册「Dapple」→「打开小红书」按钮 → 完成，不再无限转圈；不承诺相册排序。
- **首页**：长按进入多选；选择模式下分组标题旁「全选」；完成的照片不再每张都挂「RAW」，只给例外状态打标（预览、已调整、建议检查用小圆点）；处理中转圈与选中圆圈不重叠；选中圆圈始终白描边。
- **发布**：朋友圈默认原比例（1:1 作为选项）；缩略图条可移除、可调整顺序；超出张数给「拆成 2 篇」；显示全部提示而不是只显示第一条；「比例」「尺寸」行可点。
- **设置**：「默认导出尺寸」「平台预设」可点；删除无效开关「默认保持原本的调性」；「自动校正默认强度」改为「默认明暗强度」。
- **风格页筛选**：去掉 tablist 角色，改为按钮组；「中性」改名「淡雅」避免与「标准」重复。
- **编辑器标签**：8 个标签改为可横向滚动的图标 + 文字条（每项 ≥ 56 宽、44/48 高），选中项自动滚入可见区、两端渐隐；选中态用强调色浅底 + 强调色字，不再用黑块。
- **滑杆**：显示已填充段（双向滑杆从中点向两侧填充，0 点有刻度）；行高 ≥ 44（Android 48）；复位用可见的 ↺ 图标（修改后才出现，44×44）；实时更新（onInput）；`aria-valuetext`。
- **调色盘**：深色模式有深色渐变；`role="slider"` + `aria-valuetext`；键盘步进从最新状态计算。
- **实况**：在胶片条上直接拖动 3 秒窗口与封面线；按住预览播放。
- **大屏**：已改为照片为主的新布局（`Large.dc.html`：N5 横屏右侧常驻调整栏、Duo 竖屏下方两列调整区、并排对比、胶片条），旧双栏 `Unfolded.dc.html` 已删除。
- **iPhone Duo 外屏**（约 466×678pt）：手机原型增加 `device` 参数，面板高度按屏高计算。

## P2 · 规范化

- **间距**：4 / 8 / 12 / 16 / 24（页边距 16，卡片内边距 16，分区间距 24）。
- **圆角**：8 / 12 / 16 / 24 / 胶囊；Android 用 M3 形状（按钮全圆角、芯片 8、面板 28）。
- **字号**：11（标注）/ 12 / 13 / 15 / 17 / 22 / 28 / 34；iOS 只用 400 / 600 / 700。不出现 10px。
- **控件高度**：控件 44（Android 48）、主按钮 52。
- **安全区**：iOS 顶 59 / 底 34；Android 顶 36 / 底 24（手势导航）。
- **焦点**：`:focus-visible` 3px 强调色描边；对话框 `aria-modal`、Esc 关闭、点遮罩关闭、焦点移入与归还；状态消息用常驻 `aria-live` 区域。
- **单选组**用 `radiogroup/radio`；开关用 `role="switch"`；进度条 `role="progressbar"`。
- **深色 token**：toast/snackbar、遮罩、链接色、`ok` 绿色。
- **Android**：顶栏不随内容滚走；M3 分段按钮（40 高、描边、选中带 ✓）；合成方式用 M3 底部面板；列表去掉 iOS 式卡片发丝线、分区标题用主色；导航图标选中时实心；画板改为 412×945。
