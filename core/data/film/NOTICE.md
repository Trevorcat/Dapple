# Film data notice

This directory holds the data of the spectral film engine (`core/include/dapple/film.h`).

## Film and paper profiles (`profiles/*.json`, `dapple.dfp`)

* Source: **spektrafilm** by **Andrea Volpato**, <https://github.com/andreavolpato/spektrafilm>,
  `src/spektrafilm/data/profiles/*.json` (profile format version 0.3.2, created 2026-05-28).
* Licence: **CC BY-SA 4.0**. The licence text shipped with the source is in `SPEKTRAFILM_LICENSE.txt`
  (unmodified). The copyright / licence strings of every profile are preserved in the JSON files and inside
  the binary pack (`FilmStock::copyright`, `FilmStock::license`).
* Modifications: **none to the content** of the profiles. `profiles/*.json` are byte-for-byte copies.
  `dapple.dfp` is a *format conversion* of the same data (`dapple film-pack`): numbers are stored as
  float32 (little-endian, format DFP2 with a CRC32); `null` (not measured) is stored as NaN. See `CHANGELOG.txt`.
* Because the pack is a direct encoding of the profiles it is itself **CC BY-SA 4.0** and must be
  credited as: "spektrafilm by Andrea Volpato / https://github.com/andreavolpato/spektrafilm / Licensed
  CC BY-SA 4.0 - converted to binary format by Dapple". The app must show this credit (about screen).
  The author's non-binding requests apply: do not sell the data as a paid LUT pack, do not use the data
  to train commercial AI, do not use the project name in branding.
* The pack is shipped as a separate asset file next to the application code (not compiled into the
  executable). Whether that keeps the application itself outside the ShareAlike scope is a legal
  question that has not been answered here (see the open points in `docs/film/spec/01-*.md` s7).

## Data that is **not** taken from spektrafilm

| Data | Provenance |
|---|---|
| Spectral upsampling table (chromaticity -> smooth emission spectrum, 192 x 192 sigmoid-polynomial coefficients + normalisation, stored in the pack) | **Generated by Dapple** (`dapple film-upsm-gen`, `core/src/film_upsample.cpp`): own minimum-norm fit of Jakob & Hanika (2019) sigmoid-polynomial spectra to the CIE 1931 observer; deterministic (`film-upsm-gen --verify core/data/film/dapple.dfp` proves the pack holds exactly this table). Method: W. Jakob, J. Hanika, "A Low-Dimensional Function Space for Efficient Spectral Upsampling", Computer Graphics Forum 38(2), 2019. Neither `irradiance_xy_tc.npy` nor `hanatos_irradiance_xy_coeffs_250304.lut` (unclear licence) was read or used, and the rgb2spec code (BSD-3-Clause) was not copied; if it is ever ported its licence text must be added here. |
| Output gamut limit table (CAM16-UCS chroma limit, 64 x 720, stored in the pack) | **Generated by Dapple** (`buildCmaxTable`) from the CAM16-UCS formulas. |
| CIE 1931 2-degree observer, CIE D50 / D55 / D65 illuminants | CIE standard colorimetric data (as transcribed in the functional spec, `docs/film/spec/02-print-scan.md` Appendix A). |
| "Incandescent" (T) illuminant | **Generated by Dapple** from the analytic definition of CIE standard illuminant A (CIE 15:2004 eq. 3.1, ISO/CIE 11664-2); no measured data (since 2026-11-12; the earlier library sample was removed). |
| Schott KG3 heat-absorbing glass transmittance and "Kinoton 75P" lamp spectrum | Transcribed from the same spec appendix (6 significant digits). These are manufacturer / measurement data of unclear provenance; they are used only for the `TH-KG3` enlarger lamp (KG3) and the cine print stocks (K75P). A re-source of KG3 from the published Schott datasheet was investigated and not done because no reuse terms were found (`docs/film/data-licensing.md` section 5). **Re-source or replace before a commercial release** if the provenance cannot be cleared. |
| Neutral print filtration database (`neutral_print_filters.json`) | **Not used.** Replaced by an own solver (`FilmModel::solveNeutral`): Newton iteration on the full print chain for a neutral 18.4 % grey. Reproduces the reference values to about 1 CC unit. |
| Dichroic colour-head filters | Analytic erf model given in the spec (no measured curves used). |
| CAT16 / CAT02 / CAM16 / sRGB constants | Published standards. |

Full per-item provenance / licence audit, dE measurements and open points: `docs/film/data-licensing.md`. Unresolved: the `K75P`, `KG3`/`TH-KG3` and `LENS` spectra above are flagged there as items to replace or clear before a commercial release.
