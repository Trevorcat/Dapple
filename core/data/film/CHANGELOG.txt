Changes relative to the spektrafilm profile data (required by SPEKTRAFILM_LICENSE.txt)

profiles/*.json   : unchanged copies of src/spektrafilm/data/profiles/*.json (spektrafilm 0.3.2).
dapple.dfp        : binary re-encoding of the same 28 profiles, produced by `dapple film-pack`.
                    - all numeric arrays are stored as little-endian float32, "null" as NaN;
                    - density_curves_layers (256 x 3 x 3, grain model only) is stored as float16;
                    - metadata.copyright / metadata.license strings are carried over verbatim;
                    - no values were resampled, rescaled or otherwise edited.
                    The pack additionally contains two tables generated by Dapple (see NOTICE.md).
