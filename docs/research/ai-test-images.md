# Test images with an explicit CC0 / public-domain licence

Used by `scripts/ai-eval/ai_ref.py`, `portrait_report.py` and the core/ai tests. Stored under `build/ai-eval/portraits/` (git-ignored, 2048 px wide copies of the Commons thumbnails). Each licence line is the `LicenseShortName` / `UsageTerms` that Wikimedia Commons reports for the file page on 2026-11-14. Chosen only from files whose Commons licence is "CC0" (Unsplash-tagged files and nothing from the owner's personal photo folders) were avoided). Several are self-uploads by the depicted person; they are used here only as local test input and are not redistributed.

Retrieval: Commons API (`prop=imageinfo&iiprop=extmetadata`), search `incategory:CC-Zero`.
