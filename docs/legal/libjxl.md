# libjxl (JPEG XL) and Highway

* Purpose: decoding DNG 1.7 raw files with JPEG XL compression (Samsung Galaxy S22 and newer phones, Adobe DNG Converter): `core/src/decoders/dng_jxl.{h,cpp}`, built by `cmake/Jxl.cmake` behind `-DDAPPLE_JXL=ON` (default ON; OFF gives a precise "no JPEG XL decoder" error for such files).
* **libjxl v0.11.1**, decoder only (no encoder, no colour management module, no brotli / boxes, no JPEG recompression, no thread runner): licence **BSD-3-Clause**, copyright the JPEG XL Project Authors. Source: `https://github.com/libjxl/libjxl/archive/refs/tags/v0.11.1.tar.gz`, sha256 `1492dfef8dd6c3036446ac3b340005d92ab92f7d48ee3271b5dac1d36945d3d9`. Unmodified.
* **Highway 1.2.0** (SIMD abstraction libjxl needs): dual licensed Apache-2.0 / BSD-3-Clause, copyright Google LLC; used under BSD-3-Clause. Source `https://github.com/google/highway/archive/refs/tags/1.2.0.tar.gz`, sha256 `7e0be78b8318e8bdbf6fa545d2ecb4c90f947df03f7aadc42c1967f019e63343`. Unmodified.

* Cost (desktop, static archive, unstripped): libdapple_jxl.a 4.4 MB; per-platform shared-library deltas are listed in docs/engine/raw-compat.md (wave 8, round 2).
