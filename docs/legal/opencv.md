# OpenCV

* Purpose: HDR alignment / deghosting (`core/src/hdr.cpp`) and panorama stitching (`core/src/pano.cpp`), sequence detection (bracket sets, panorama runs). Used on every platform that builds the engine with `DAPPLE_WITH_OPENCV=ON`: Android, the desktop test builds and, since 2026-11-14, iOS / macOS.
* Version and source: OpenCV 4.12.0, the upstream release tarball `https://github.com/opencv/opencv/archive/refs/tags/4.12.0.tar.gz`, SHA-256 `44c106d5bb47efec04e531fd93008b3fcd1d27138985c5baf4eafac0e1ec9e9d` (pinned in `cmake/OpenCV.cmake`; the same source tree, the same CMake file and the same module list as Android and the desktop).
* Licence: Apache License 2.0 (OpenCV 4.5 and later). The shipped binary links no contrib or non-free module: no SIFT / SURF, features are ORB and AKAZE only. The app's licences screen lists "OpenCV, Apache-2.0".
* Modules (static libraries, linked into `libdapple` / `dapple.framework`): core, imgproc, features2d, calib3d, flann, stitching, photo, video. OpenCV's bundled zlib (zlib licence) is built with it. Everything else is off: no OpenCL, IPP, TBB, OpenMP, Eigen, LAPACK, codecs (JPEG / PNG / TIFF / WebP), videoio, highgui, dnn, ffmpeg, GUI.
* iOS / macOS (2026-11-14): not a prebuilt xcframework. The pinned source is cross-compiled by the engine's own CMake build for iOS device, iOS simulator and macOS arm64 (`scripts/ios/build-engine.sh`; the source tarball is staged into the Mac checkout by `scripts/ios/stage-opencv.sh` under `tools/_dl/opencv`, never fetched at build time on the Mac). Reason: the official release xcframework contains all modules, including the ones the engine does not use, and is a binary we could not audit against the module list above. A static, module-limited build adds about the size of the used objects only (see docs/ios/README.md for the measured size).
* Clean-room note: OpenCV is used through its public headers only; nothing from GPL / CDDL projects is ported.
