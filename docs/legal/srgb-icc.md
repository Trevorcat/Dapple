# Embedded ICC profiles (sRGB, Display P3)

Provenance: the profile bytes are generated by `buildIccProfile` in `core/src/exif_writer.cpp`; no profile file from any vendor is copied or embedded.
They are written from the ICC specification (ISO 15076-1:2010 / ICC.1:2022 v4.4 structure: 128-byte header, tag table, `mluc`, `XYZ `, `para` types).

Content (all public colorimetry, not creative work):
- sRGB: IEC 61966-2-1 primaries and D65 white, colorants adapted to the D50 PCS with the Bradford matrix (0.4360747 0.2225045 0.0139322 / 0.3850649 0.7168786 0.0971045 /
  0.1430804 0.0606169 0.7141733), transfer curve as parametricCurveType 3 (g 2.4, a 1/1.055, b 0.055/1.055, c 1/12.92, d 0.04045).
- Display P3: P3 primaries with D65 white (SMPTE EG 432-1), D50-adapted colorants (0.5151146 0.2411999 -0.0010521 / 0.2919776 0.6922491 0.0418842 /
  0.1571181 0.0665510 0.7840791), same curve. Built and tested; no export path uses it yet (the render pipeline ends in sRGB).
- Description "sRGB" / "Display P3", copyright text "No copyright, use freely". The creation date is fixed so the bytes are reproducible. About 480 bytes each.

The test `export_meta.icc` parses the generated profile with the engine's own matrix / TRC reader and compares matrix and curve with the engine's sRGB constants.
