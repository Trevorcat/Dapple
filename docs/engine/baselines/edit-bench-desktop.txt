# edit-bench desktop baseline (step a0 of docs/engine/pipeline-architecture.md 10.2)

Recorded from the current renderer (DAPPLE_ENGINE unset = off) with:
    dapple edit-bench <24 MP Sony ARW, decoded at preview quality, resized to 2048 long edge> --repeat 8
Machine: Intel Core i7-14700KF (20 cores / 28 threads), Windows 10, Release build (build/engine-a, llvm-mingw clang -O3).
Timings are medians of 8 runs after one warm-up. Run-to-run spread on this shared machine is 5-50 % per row (other
builds were running), so use these as order-of-magnitude references and compare A/B only with interleaved runs.
The photo is private and stays on this PC; its path is replaced below.
Throttle profiles (tools/throttle) were NOT run for this baseline (optional per the task).
