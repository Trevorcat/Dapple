## A. 规则清单（从三份文件提炼，下文用编号引用）

**原则**
- R1 所见即所触：绝对映射，光标在手指下；照片上只有缩放、平移、按住对比（15.1-1）。区域形状例外（local 2）。
- R2 按意图分层：第 1 层照片 + 坞；第 2 层 一块盘面 + 一条强度条，不滚动；第 3 层“分项” = 性格图 + 一把尺子；复杂编辑器是第 3 层的附加入口（15.1-3，panel 1）。
- R3 默认 = 简化操作，细调只在“分项”后；不成排滑杆、不出第二层菜单、不横向长列表（15.1-3，local 7、9.1）。
- R4 强度条：最下 0 = 没效果，中线 100 %，往上更重；吸附中线，触感地标（15.1-5、15.1-8）。
- R5 盘面不写字，图标讲意思；六对图标全 App 通用（15.1-6）。
- R6 交互中不重排；面板高度跟着当前层的内容，分类内换层用动效过渡，不留空白带（15.1-7，v0.8）。
- R7 自动是起点：复位、单项复位；不用确认框，用撤销（15.1-9）。
- R8 一个元素三份工作（坞字形 = 入口 + 状态 + 读数），按住坞项弹出盘面（15.1-4）。
- R9 照片最大：照片边长至少保持无面板时的 90 %（盘面能有 150 dp 时）；N5 外屏下方、横屏 / 内屏一侧（panel 7）。
- R10 亮色优先，随系统切暗；无应用内主题开关（1.3）。
- R11 状态不只靠颜色（1.6、12.1）。

**编辑器组件**
- R12 坞：胶囊 56 高（规格下限，不要求各处等高）；选中 = `tabActiveBg` + `accent`（15.2.2；panel 3 写 `accentSoft`）；按住 260 ms 弹出盘面。
- R13 页眉：标题 + 读数 +（复位）+ 分项；复位未改动时隐藏但占位（10.4、panel）；复杂编辑器中“分项”位置变“返回”。
- R14 分项：性格图 + 一把跟手尺子，单项复位，点数值键入（panel 5）。
- R15 按住弹出：坞项按住、胶片地图按住放大，松手保留并关闭；整个按住 = 一个撤销步（panel 3、4）。
- R16 对比：编辑器内长按照片 380 ms；**界面上不放对比按钮（负责人决定）**（12.2、9）。local 9.1 另设页眉「对比」。

**文案（13）**
- R17 简洁直接；不写说明句、提示句；不写“请”；无感叹号；无 emoji。
- R18 一个元素一个词；动词开头 = 动作，名词 = 状态。
- R19 失败 = 发生了什么 + 下一步按钮，**不写原因猜测**。
- R20 无学术 / 技术栈词（FTP、LibRaw、线性、16 位……）；不出现“智能”“AI 帮你”；局部禁词：蒙版、羽化、组件、图层、交集、AI、智能、模型、分割。
- R21 格式：中英 / 数字之间半角空格；“ · ”并列；「」命名对象；会再弹界面的操作加“…”；提示条与标题不带句号。
- R22 不用“加载中”；能确定的进度用确定性进度（10.13）。

**令牌**
- R23 颜色只取令牌（`context.c` / `Fx`），不在控件里硬编码（2.1 末）；照片上的文字放 ≥ 50 % 黑衬底（2.4）。
- R24 间距 2 / 4 / 8 / 12 / 16 / 24，4 的倍数（4）。
- R25 圆角 8 / 12 / 14 / 16 / 20 / 24 / 28 / 胶囊（5）；Android chip 32 高、圆角 8、描边（10.2）。
- R26 字号阶梯 34 / 28 / 22 / 17 / 15 / 13 / 12 / 11，不小于 11；数字等宽（3）。
- R27 动效：弹簧 150 / 200 / 350 ms 三档，可打断，尊重减少动态效果（15.3）。

**图标（8）**
- R28 24 格线性、描边 2、圆头，自绘、单色 `currentColor`；不用 emoji、不用彩色图标（色点、色样、成像图标除外，10.2）；每个图标按钮有语义标签。

**空状态 / 进度 / 失败**
- R29 空状态 = 一句状态 + 一个下一步按钮（13.4）。
- R30 进度位置固定，确定性优先，后台任务可见；失败给下一步（10.13、13.4）。

**触控与布局**
- R31 命中区 ≥ 48 dp（Android）/ 44 pt；视觉小于下限的扩命中区（6、12.1）。
- R32 自适应（因地制宜，第 0 节）：下方 / 一侧两种布局取照片更大者；铰链带不放控件；inset 运行时读取（panel 7、15.6）。
- R33 字号放大 200 % 不截断，图标同步放大（3、12.6）。
- R34 每个自定义手势都有等价可见操作或语义动作（12.2、15.5）。

## E. 统一提案（每项一条规则，可直接并入指南）

- **U1 强度条**：最下 = 没效果；**中线 = Dapple 推荐的量，读作 100 %**；最上 = 这个控件能给的最多（一般 200 %，配方有上限时以上限为顶，读数显示真实百分比，如人像肤质顶 = 333 %）。吸附中线有触感。凡有强度条的面板，页眉读数位置都显示“强度 N %”。光线的“推荐”= 设置里的默认明暗强度；局部 = 引擎 100；人像 = 43.8 的推荐值。三者含义统一为“推荐”，不需要三套说法。
- **U2 加 / 减模式**：在照片上“添加或去掉”的工具（画笔、点选、祛斑点）一律在工具条左端用同一个 [+|−] 分段，默认 +；不用开关图标、不用“点在已有处去掉”、不在动作卡里放“涂抹补充 / 擦除”。
- **U3 对象上的动作**：点未选中的芯片 = 选中；**再点已选中的芯片 = 打开它的动作卡**（选中的芯片右下带 ⌄ 作可见入口）；破坏性动作（删除、去掉）只在动作卡里，执行后提示条带「撤销」，不用确认框。人像芯片的开 / 关是动作卡里的第一格（或芯片上的开关点），不是再点。
- **U4 对比**：全 App 只有一种：按住照片 380 ms 看原片（局部里看“没有任何区域”的照片）；局部里起点在手柄上的按住归手柄，起点不在手柄上且不动的按住 = 对比；画笔在移动 8 dp 后才落墨。界面上不放「对比」按钮（维持 12.2）。
- **U5 设置类选择**：二值 = 开关（整行可点）；三个以内互斥值 = 分段；更多值或需要预览 = 带 › 的行打开底部面板；› 只表示“会打开界面”，不做“点行循环”。发布页与设置页同一项用同一控件。
- **U6 页眉**：`[‹]标题 · 读数或副标题 ……（复位）· 主动作`。标题永远是坞项名（局部里不变成“人像”“加一块”，这些作副标题）；进入任何下一层（分项、复杂编辑器、卡片、地图）后标题左侧出现 ‹，按 ‹ 或系统返回回到上一层；最右只放本层的主动作（分项 / 加上 / 无）；页眉最多 3 个按钮，多出的放第二行。
- **U7 选中与开**：持久选中 = `accentSoft` 底 + 1.5 `accent` 描边（芯片、图标格、胶卷盒、风格点统一，风格点在盘面上用白底环外加 accent 描边）；“开着但不是当前”= `accentSoft` 底无描边；实心 `accent` 只用于“按住期间”的瞬时状态（按住对比、按住弹出）和主按钮。图标格（区域种类、动作、人像）用同一个组件：最小 56×56、圆角 16、图标 24 + 11/12 字。
- **U8 名词**：成像 = 底（标准 / 现代 / 胶片），风格 = 叠在上面的颜色风格，区域 = 一个可调的地方，块 = 区域里的一个形状（画笔、AI 平面也是块），部位只出现在“人物”卡里。坞项“胶片”改名“成像”。
- **U9 进度与失败**：每个后台 / 异步动作必须有：确定进度（能算就算，否则转圈但不写“加载中 / 读取中”）、取消（> 2 秒的）、失败 = 一句发生了什么 + 「重试」（只在重试有意义时），没找到 = 一句“没找到 X”。提示条是失败的默认载体，带动作。
- **U10 命中区**：所有可点件命中 ≥ 48×48，用统一的 `HitBox` 包装，视觉尺寸自由；拥挤时换行，不缩命中区。

## F. 做得好的、应写成规则的

1. **空状态即第一步**：局部没有区域时，面板身体直接是形状卡（`local_panel.dart:294-297`）；没有说明句、没有灰掉的控件。

7. **复位按钮隐藏但占位**，页眉不跳（`pad_panel.dart:406-411`、`local_panel.dart:66-71`）。

9. **整张卡可点**（连接卡，`conn_card.dart:45-50`）。
10. **失败原因从错误码映射成白话**（`models.dart:134`）——方向对，文字要按 C 表改。
11. **拖动中面板不重建、一个手势一个撤销步**（panel 7、local 8）。
