# 编辑器控制面板（盘面 + 强度，照片下方或照片一侧）

版本 0.6（2026-11-12）。范围：**所有屏幕**。负责人认可的交互稿：`dapple-panel.html`（强度和方向，第七版）。原则见 `guidelines.md` 15.1（v0.6 重写）。代码：
`app/lib/model/pad_model.dart`（配方、条目、盘面状态；纯 Dart）、`model/film_map.dart`（胶片地图的布局）、`screens/editor/pad_panel.dart`（面板、页眉、第 2 / 3 层、裁切、复杂编辑器）、`pad_widgets.dart`（盘面、强度条）、`pad_dock.dart`（坞的活字形方块、按住弹出）、`film_map_view.dart`、`itemised_view.dart`（性格图、尺子）、`pad_icons.dart`（图标）、`pad_gestures.dart`、`editor_controller.dart`、`editor_page.dart`、`editor/panel_layout.dart`（照片下方 / 一侧的几何求解，未变）。测试：`test/pad_panel_test.dart`、`test/model/pad_model_test.dart`、`test/editor/panel_layout_test.dart`。

## 1. 为什么改

负责人的话：一条滚动的芯片条里堆了太多东西；看到什么就要碰到什么；层级必须清楚。真机试用推翻了 v0.5 的几条：照片上相对拖动改值（手指和值脱节）、尺子指针固定（像滑杆）、芯片条罗列十几个参数。v0.6 的结构：

| 层 | 内容 |
|---|---|
| 1 | 照片 + 底部坞：光线、颜色、胶片、质地、裁切。前四项是活字形方块：方块里的点 = 盘面位置，旁边细条 = 强度；一个元素 = 入口 + 状态 + 读数 |
| 2 | 点一个坞项：**一块盘面（两个方向）+ 一条竖直强度条**，没有别的，不滚动 |
| 3 | 页眉的“分项”：该分类的全部参数画成性格图（雷达图），下面**一把尺子**；复杂编辑器（曲线、分色、分级、相纸）是附加入口 |

照片上的手势只剩缩放、平移、按住对比（点一下仍折叠 / 展开面板）。删除：照片上拖动改值、“照片即垫板”、芯片条、相对映射、尺子固定指针。

## 2. 强度条和盘面

强度条（`a`：0..1，0.5 = 100 %，吸附 ±0.03；拇指在手指下，可用范围是条高的 10 %..90 %）：

| 分类 | 条 = 什么的强度 | 对应参数 |
|---|---|---|
| 光线 | 自动调光 | `toneStrength`：下 0，中 = 用户默认（设置里的明暗强度，缺省 60），上 100 |
| 颜色 | 风格 | `lookStrength` 下 0，中 100；上半不超过引擎的 100，改为加重鲜艳度 / 饱和度 |
| 胶片 | 胶片效果整包 | 下半：`film_strength`、`film_grain`、`film_halation` 从 0 升到 100；上半：强度保持 100，颗粒、光晕升向参数范围的上限（从 param spec 读，引擎 schema 现为 200 %），黑位抬起（`film_black` 到 −0.5） |
| 质地 | 默认锐化和降噪 | 下 0，中 = 默认（锐化 40、颜色降噪 25），上半约 ×1.8 |

`film_grain`、`film_halation` 的上限不写死：配方读 `specByKey` 的 max（`params.dart` 与 `core/src/edit_params.cpp` 同为 200）。

盘面（x、y：−1..+1，中心 = 自动，每轴吸附 ±0.04；光标可达范围 = 盘面缩进 22 dp，所以光标永远在手指下面）：光线 x 暗↔亮、y 反差低↔高；颜色 x 冷↔暖、y 淡↔浓；胶片 x 淡↔浓（`film_shoot`）、y 暗↔亮（`film_print`）；质地 x 柔↔锐、y 干净↔颗粒。

### 配方表（`padRecipe(cat, x, y, a)`，纯函数；中心 x = y = 0、a = 0.5 时每一项恰好等于参数默认值，有单元测试）

| 分类 | 参数 | 值 |
|---|---|---|
| 光线 | `exposure` | 16 x（±0.8 EV） |
| | `contrast` | 55 y |
| | `highlights` | −40 x − 15 y |
| | `shadows` | 20 x − 15 y |
| | `whites` / `blacks` | 15 y / −15 y |
| | `toneStrength` | 见上，随 a |
| 颜色 | `temp` | 30 x |
| | `vibrance` | 55 y + 20 b |
| | `saturation` | 25 y + 8 b |
| | `lookStrength` | 100 · min(1, 2a) |
| | （b = max(0, 2a − 1)；`tint` 恒 0） | |
| 胶片 | `film_shoot` / `film_print` | 0.8 x / 0.65 y（留在引擎安全范围内，再受 `effective_lo / hi` 夹住） |
| | `film_strength`、`film_grain`、`film_halation` | 100 · min(1, 2a) |
| | `film_grain` / `film_halation` 上半 | 100 + b (max − 100) |
| | `film_black` | −0.5 b |
| 质地 | `clarity` / `texture` | 40 x / 20 x |
| | `sharpen` | (40 + 40 x) k，0..150（k = 2a 到中间，之后 1 + 0.8 b） |
| | `nrLuma` | (60 · max(0, −y) + 25 b)，下半随 min(1, 2a) |
| | `nrColor` | (25 + 40 · max(0, −y)) k，0..100 |
| | `grain` | 45 · max(0, y) |
| | `sharpRadius` / `dehaze` / `vignette` | 恒 10 / 0 / 0（只在分项里调） |

所有值夹在各自参数范围内（测试扫过整个盘面和整条强度条）。

### 持久化与旧编辑

`EditState.pads`：`{light | color | film | texture: {x, y, a, off: {参数: 偏移}}}`，随 `toJson` 存、`fromJson` 容错读、随粘贴 / 同步按分类带走；**不进 `toWire`**（引擎看到的只是普通参数）。盘面在中心且没有偏移时不存。

- 参数值 = 配方 + 偏移；分项里改一项 = 值照写、盘面不动、差值成为该项的偏移（`setItemValue`）；盘面再动，偏移保留。
- 没有盘面状态的旧编辑：盘面在中心，强度条按强度项反推（光线按 `toneStrength`，颜色 / 胶片按 `/200`），其余已有的值显示为该项的偏移（`padStateOf`），第一次拖动不会让任何旧值跳变。
- **调色盘 `palette` 并入颜色盘**。引擎的 palette 是风格自己的 2D 颜色引导（x 淡→浓、y 暖→冷，范围 0.04..0.96），和颜色盘的两个方向（冷暖、淡浓）是同一件事，风格预设点本来就摆在各风格自己的 palette 点上（`palettePadPosition`）。所以：读旧编辑时（`EditState.fromJson` → `migratePalette`）把 palette 换成颜色盘光标位置（已有的值作为偏移保留），并且**不再下发 `palette`**（`toWire` 不写）。代价：带 palette 的旧编辑画面会按颜色盘配方重新算一次，略有变化。
- **明暗目标 `toneTarget`**（光线强度条放大 / 缩小的自动调光目标）在 光线 → 分项 → “明暗目标”里有 3×3 编辑器（绝对映射，每格是这张照片在该目标下的缩略预览，白点 = 与这张最接近，“回到自动”清除）；光线复位也会清掉它。
- 下发引擎的每个参数在界面里都看得到、改得了、复位得了：`sharpRadius` 在质地分项里。
- 胶片盘无胶片时，第一次碰盘面 / 强度条自动选默认片（N400C，没有则第一支）。

### 盘面的样子

盘面占满整块区域（无内边距、圆角 18），渐变只在颜色本身解释的地方：光线 深灰→近白；颜色 蓝→灰白→橙，向下渐隐成灰；胶片 暖中性（下暗上亮）；质地 中性灰。细点阵 16 dp；四条边中点（距边 20 dp）各一个白色细线图标，带细阴影；盘面上没有文字。中心一个小圆环 = 自动。光标：28 dp 白环，阴影。胶片盘中引擎判定无效的一端（`effective_lo / hi`）盖暗并不可达（光标夹在中线）。

图标词汇（全 App 一致）：月 / 日 = 暗 / 亮；两个半明半暗的圆（弱、强）= 反差低 / 高；蓝点 / 橙点 = 冷 / 暖；空心 / 实心水滴 = 淡 / 浓；波 / 锯齿 = 柔 / 锐；空 / 点圆角方块 = 干净 / 颗粒。路径来自原型的 `I` 对象，用 `Path` 画在 20×20 格上（不引入 flutter_svg）。

## 3. 坞和按住弹出

坞：五项（光线、颜色、胶片、质地、裁切），胶囊高 56。字形：24 dp 圆角方块（胶片是圆）、十字细线、一个点（盘面位置）、右侧一根细条（强度，高 2 + 22 a dp）；强度 0 或胶片未选时整体淡到 38 %。选中 = `accentSoft` 底 + `accent`。“更多”（发布、复制 / 粘贴设置、同步、还原）移到顶栏右侧胶囊的“…”。

按住一个字形（260 ms）或直接在上面拖超过 8 dp：盘面在坞上方弹出（216 dp，圆角 26，投影），面板收起、照片保持全尺寸；拖动相对按下时的值（一整个量程 = 94 dp 手指位移）；松手收回，值保留，不打开面板。短按仍打开面板。整个按住是一个撤销步。

## 4. 胶片

页眉：`无`按钮（清掉胶片）和当前胶片按钮（`N400C ⌄`）并排。点胶片按钮：盘面和强度条换成**胶片地图**（分项里这两个按钮隐藏，页眉让给复杂编辑器入口）。

- 每支片是一个点，位置 = 性格：x 淡→浓、y 反差低→高（和盘面同一套图标，画在四边）；颜色按类型：负片琥珀、反转片蓝、电影青。
- 位置来自 `assets/film/film_map.json`（`{片 id: {x, y, type, code}}`，由 `scripts/film/gen_film_map.py` 量出，见 `docs/film/film-map.md`）；文件里没有的片按自动网格排；然后把靠得太近的点互相推开（参考图 340×210 dp，点心距不小于 27 dp），保持相对次序。
- 按住：手指周围放大 2.4 倍（260 ms 缓动，以按下点为中心），所有名字显示；手指不抬，滑到最近的点（手指位移 / 2.4 = 地图位移），照片实时跟着换；松手保留，地图缩回；不放大时只有选中的片显示名字。整个按压是一个撤销步。
- 四个边缘图标放大时淡出（否则正好在片子中间），不放大时点不会躲在图标下面（地图在 −1..1 之外留 12 % 的边）。`无` 在页眉：清掉胶片（连同所有胶片参数和胶片盘状态）。再点页眉按钮回到盘面。

## 5. 分项（第 3 层）

页眉的“分项”：性格图 + 一把尺子。

- **性格图**：占满面板宽度，半径在面板位于照片下方时至少 80 dp（名字单行排在图外，按名字宽度算出半径，不截断）；选中的辐条加粗、点放大、所在扇区淡色填充，名字加底色。每个参数一根辐条；虚线多边形 = 盘面位置隐含的值，实线多边形 = 加上分项偏移后的值。按在图里：**方向选辐条，离中心的距离定值**，整次手势辐条锁定；按在外圈（名字所在处，每项一个宽扇区）只选不改。
- **尺子**：只有一把，对应选中的参数；刻度带**跟手**（向右拖，刻度向右移，值变小；一个刻度 = 量程的 1 %，7 dp）；值（名字 + 数）在上方，点数值键入；档位触感在自动位和范围两端；偏离盘面隐含值时右上角出现单项复位。参数名用文字。
- 复杂编辑器的入口在页眉（分项里原来放读数的位置）：光线 → 明暗目标、曲线；颜色 → 分色、分级；胶片（印制负片）→ 相纸；窄页眉里按钮会等比缩小，不溢出。
- 条目：光线（曝光、对比度、高光、阴影、白色色阶、黑色色阶、明暗强度）；颜色（色温、色偏、鲜艳度、饱和度、风格强度）；胶片（拍摄曝光、冲印深浅、胶片强度、颗粒、光晕、黑位、白平衡、宽容度；印制负片再加冲印冷暖、冲印色调）；质地（清晰度、纹理、锐化、锐化半径、明亮度降噪、颜色降噪、颗粒、去雾、暗角）。
- **复杂编辑器**（打开后占满面板，页眉“返回”）：光线 → 明暗目标（见上）、曲线（四通道、四点；绝对：曲线过手指所在的高度）；颜色 → 分色（八个色范围圆点 + 色相 / 饱和度 / 明亮度 + 尺子）、分级（四个区域、色轮：绝对，手指的角度 = 色相、离心距离 = 饱和度；明亮度 / 混合 / 平衡 + 尺子）；胶片（印制负片）→ 相纸。

## 7. 布局与行为（未变的部分）

- **自适应**：对当前屏幕、照片宽高比算出“下方”和“一侧”两种布局，取照片更大的（侧窗格要大 8 % 以上才算赢）；规则和矩阵见 `panel_layout.dart` 与 `test/editor/panel_layout_test.dart`。N5 外屏在下方，展开的内屏竖构图、横持手机、平板在一侧。
- **面板高度（v0.6 规则）**：照片的边长至少保持无面板时的 90 %，只要盘面还能有 150 dp 高（盘面和强度条一起缩，盘面可以比高更宽）；低于这个再让照片缩得更小。`bottomPanelHeight(region, photoW, aspect, screenH)`：允许的面板高 = 区域高 − 8 − 0.9 × 无面板照片高，夹在“盘面 150 dp”和“舒适的 236 dp”之间（加抓手、页眉、边距 74 dp），再不超过屏高的 46 %。N5 外屏：3:2 照片 310 dp（舒适），3:4 约 254 dp（盘面约 180），2:3 为 224 dp（盘面 150）。在一个分类内，盘面、胶片地图、复杂编辑器高度相同；分项（性格图，需要半径 80 的雷达和一把尺子）可以更高（内容 290 dp，总高不超过屏高 46 %），照片在这一层多缩一点。屏宽大于 600 dp 时下方面板居中，宽度不超过 600 dp。一侧窄窗格的页眉有第二行放读数。
- **折叠**：抓手（点击或上下划）折成“抓手 + 页眉”；点照片空白处同样折叠 / 展开。返回键顺序：数值输入 → 复杂编辑器 → 分项 / 胶片地图 → 折叠 → 关闭 → 退出页面。
- **性能**：拖动盘面 / 强度条 / 尺子 / 性格图时，面板不重建（测试里 `debugPanelBuilds` 不变）；只有光标层、强度条、坞的字形、页眉读数各自在 `RepaintBoundary` 里按 `editTick` 重绘；一次手势 = 一个撤销步；引擎照旧 `beginInteraction(activeParam)`。
- **手性、暗色、大字号**：沿用；暗色盘面的渐变微调；1.6× 字号测过无溢出。
- **调试入口**（仅 debug 构建，`lib/services/debug_open.dart`）：`{"photo":3,"group":"light","row":"items","pad":{"light":[x,y,a]},"hold":"light","reset":true,"stock":"kodak_portra_400"}`。`group`：light、color、style（= 胶片）、effects（= 质地）、crop；`row`：items、map、curve、hsl、grade、paper、tone；`look`：选风格。

## 8. 已知粗糙之处

- 分项层比盘面层高（雷达需要），从盘面切到分项时面板和照片会动画变化一次；这是“分项可以更高”的代价。
- 一侧窄窗格（约 288 dp 宽）里雷达半径只有约 55 dp（名字单行排在图外要占掉宽度）。
- 颜色预设点叠在配方之上：点一个预设 = 选风格 + 光标移到该点，配方再加一点色温和鲜艳度，所以不是纯粹的“该风格”。
- 带旧 `palette` 的编辑，读入后画面按颜色盘配方重新计算，和原来略有差别。
- 配方的幅度是在两张照片的九个位置（中心、四角、四边中点）上看渲染调的；质地的差别在缩略对比图里看不出来，没有在更多照片上验证。
