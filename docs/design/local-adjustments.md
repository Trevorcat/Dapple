# 局部调整（区域 = 哪里 + 怎么调）

版本 0.3（2026-11-14；0.2 加入 AI 区域，0.3 加入人像，第 9 节）。范围：所有屏幕。引擎契约：`docs/engine/pipeline-architecture.md` 第 40 节（40.1 数据模型、40.6 界面契约）。沿用 `guidelines.md` 15.1（v0.6）与 `editor-panel.md` v0.6 的全部规则，本文只写局部调整新增的部分。代码：`lib/model/local_adjust.dart`（数据，与引擎 JSON 逐键一致）、`lib/model/local_kinds.dart`（区域种类登记表）、`lib/model/local_pad.dart`（配方）、`lib/editor/mask_geometry.dart`（坐标、手柄几何）、`lib/native/local_bindings.dart`（新增的 C 调用）、`lib/screens/editor/local_controller.dart`、`local_layer.dart`（照片上的手柄、画笔、蒙版色）、`local_panel.dart`（面板、区域芯片、工具条）。

## 1. 用户怎么想

一张照片有**几个区域**。每个区域 = **哪里**（照片上的一块形状：渐变、圆形、画笔、明暗、颜色）+ **怎么调**（和全局完全一样的盘面 + 强度条）。区域是一个短名单，不是图层面板：用户不需要知道"蒙版""组件""羽化"这些词。

- 哪里：直接在照片上摆、拖、画。手指碰到的就是形状本身（所见即所触）。
- 怎么调：光线盘（暗↔亮、反差）、颜色盘（冷↔暖、淡↔浓）、强度条；分项里是全部局部参数。用户不学第二套控件。

## 2. 入口：坞里的第六项「局部」

放在「质地」和「裁切」之间。理由（对照指南）：

- 局部是一个与分类正交的维度（"哪里"），不是某个分类里的一个参数。放进光线 / 颜色 / 质地各自里面，就要在四个地方各放一个区域选择器（深层菜单、重复），违背 15.1 原则 3（按意图分层）。
- 一个入口 = 一个模式：坞上选中「局部」时照片进入"编辑区域"状态，关掉它照片就回到缩放 / 平移。模式由坞的选中态、照片上的手柄和红色蒙版色三样同时表明，不会混淆（原则 6：状态不只靠颜色）。
- 坞六项在 N5 外屏放得下（每项 ≥ 52 dp）。字形是活的：当前区域的形状小图标，右上角一个数字点 = 区域个数；没有区域时淡到 38 %，与其他字形同一规则。

**照片上的拖动不违背"照片上不做调节手势"**。那条规则针对全局参数：在照片上相对拖动改曝光，手指和值脱节。区域的形状本来就长在照片上，手指按住的就是形状本身——这是绝对的、直接的操作，正是原则 1。调节量（曝光、冷暖……）仍然只在面板的盘面上改，照片上从不改调节量。

## 3. 流程

```
① 点坞「局部」           ② 点 +，选形状              ③ 在照片上摆放
┌────────────────────┐  ┌────────────────────┐  ┌────────────────────┐
│                    │  │                    │  │  ════════════  ←满 │
│      照  片        │  │      照  片        │  │  ┄┄┄┄┄┄┄┄┄┄┄┄  ←无 │
│  （手势：缩放平移）│  │                    │  │   红色 = 被选中处  │
│                    │  │ ┌────────────────┐ │  │      ⟲ 旋转钮      │
├────────────────────┤  │ │ ▤  ◯  ✎  ◐  ◍ │ │  ├────────────────────┤
│ 局部   [+]     分项│  │ │渐变圆形画笔明暗颜色│ │  │ 局部 [+][▤]   分项 │
│ ┌──┐ ┌────┐┌────┐ │  │ └────────────────┘ │  │ ┌──┐ ┌────┐┌────┐ │
│ │  │ │光线││颜色│ │  ├────────────────────┤  │ │强│ │光线││颜色│ │
│ │强│ │ 盘 ││ 盘 │ │  │ 局部 [+]       分项 │  │ │度│ │ 盘 ││ 盘 │ │
│ └──┘ └────┘└────┘ │  │       （同左）     │  │ └──┘ └────┘└────┘ │
└────────────────────┘  └────────────────────┘  └────────────────────┘
空状态：只有 [+] 芯片，盘面画出但淡显不可用。
```

1. **加区域**：页眉里的 [+] 芯片 → 一张小卡片，五个图标（下面一个小字：渐变、圆形、画笔、明暗、颜色），不是文字列表。卡片里的种类来自登记表（第 9 节）。
2. **摆放**（照片上，单指）：
   - 渐变：新建时从照片上缘到中部。两条线：实线 = 满效果，虚线 = 无效果；拖实线 / 虚线各自移动，拖两线之间平移，拖线中点外侧的小圆钮旋转。在手柄以外的空白处拖 = 重新画一条（从按下处满到松手处无）。
   - 圆形：新建时在照片中央。椭圆实线 = 满效果边界，外圈虚线 = 渐隐到无（羽化）；拖里面平移，拖实线上的四个点改宽 / 高，拖外圈改羽化，拖上方小圆钮旋转。手柄以外拖 = 以按下处为中心画一个新的。
   - 画笔：单指画，双指缩放 / 平移（画笔时缩放是常态）。粗细、擦除在照片底部的工具条（第 5 节），粗细按屏幕大小定：放大后同一档更细，正好用于细处。笔压不用。
   - 明暗 / 颜色：新建时取照片中央那一点；之后**在照片上点一下**就取那里的明暗 / 颜色。范围宽窄在照片底部的工具条上拖（第 5 节）。
3. **调整**：盘面 + 强度条，与全局一模一样（第 4 节）。
4. **合并**（同一区域再加一块）：点已选中的区域芯片 → 小菜单：加一块… / 减一块… / 反选 / 复制 / 删除。加一块 / 减一块 再出同一张形状卡片。规则只有一条：加形状 = 并上；加明暗 / 颜色 = **限定在**这块里（"这片天，但只要亮的地方"）；减 = 去掉。一个区域多于一块时，工具条左端出现每块的小图标，点哪块就编辑哪块，选中的那块带 ×。
5. **排序**：v1 不做。局部调整彼此几乎可交换（都是在场景光上乘），用户感知不到次序。

## 4. 怎么调：同一套盘面

```
竖屏（照片下方）                          横屏 / 内屏（照片一侧的窄窗格）
┌─────────────────────────────────────┐   ┌───────────────────┐
│ 局部  [+][▤][◯•][✎]   复位  分项    │   │ 局部     复位 分项│
│ ┌───┐ ┌─────────────┐┌─────────────┐│   │ [+][▤][◯•][✎]     │
│ │   │ │ ☾    光线  ☀ ││ ●  颜色   ● ││   │ ┌──┐ ┌──────────┐ │
│ │ ● │ │      ○      ││      ○      ││   │ │  │ │  光线盘  │ │
│ │   │ │             ││             ││   │ │强│ └──────────┘ │
│ └───┘ └─────────────┘└─────────────┘│   │ │度│ ┌──────────┐ │
└─────────────────────────────────────┘   │ │  │ │  颜色盘  │ │
                                          │ └──┘ └──────────┘ │
                                          └───────────────────┘
```

- **两块盘面同时在**（竖屏左右并排，窄窗格上下叠放），不切换：看到什么就碰到什么。图标与全局一致：月 / 日、弱 / 强反差、蓝点 / 橙点、空心 / 实心水滴。
- **强度条**：下 0（区域无效果）、中线 100 %（引擎 `strength` 100）、上半把盘面配方加重到 2 倍。和全局强度条一样吸附中线。
- **配方**（纯函数，中心 = 全 0）：曝光 30 x（±1.5 EV，局部常需要比全局大的幅度）、对比度 40 y、白色色阶 10 y、黑色色阶 −10 y；色温 40 x、饱和度 30 y、鲜艳度 15 y。上半 ×(2a)。
- **分项**：页眉换成三个芯片 [光线][颜色][质地]，下面是该组的性格图 + 一把尺子（全局分项同一控件）。光线：曝光、对比度、高光、阴影、白色色阶、黑色色阶；颜色：色温、色偏、饱和度、鲜艳度；质地：清晰度、纹理、锐化（负 = 柔化）、降噪、去雾。分项改值 = 偏移，盘面不动（同全局 `setItemValue`）。`color_hue / color_sat`（给区域加一层颜色）v1 不露出，数据原样保留。
- 页眉的"复位"= 把当前区域的调整回到 0（形状不动）。

## 5. 照片底部的工具条（"哪里"的细调）

只在需要时出现，浮在照片区域底边上方 8 dp，实底 `surface`、圆角 20、高 48，水平居中，不滚动：

```
画笔：  [▤|◯]  ·  ∘  ○  ◯  ⬤   ·  [擦]          （四档粗细画成真实大小的圆）
明暗：  [▤|◐]  ·  ▕■■■▓▓▒▒░░□□▏ 带两个把手     （黑→白的条，亮出的是被选中的明暗段）
颜色：  [▤|◍]  ·  ▕彩虹色相条，亮出的是选中段▏
渐变 / 圆形：只有一块时不出现
```

- 明暗条：拖两端把手改范围，拖中段整体移动；边缘的渐隐画在条上（羽化固定 10，v1 不单独露出）。颜色条同理（色相 ± 宽度；最低饱和度固定）。
- 在照片上点一下 = 取样（`dapple_session_mask_sample_json`），条上的段跳到那里，宽度保持。

## 6. 蒙版色（红色覆盖）

- 显示：在照片上摆放 / 拖手柄 / 画笔时及松手后 1.2 秒；新建或切换区域时闪 1.2 秒；区域还没有任何调整时一直显示（否则看不出选中了哪里）；**按住区域芯片**时显示。
- 隐藏：拖盘面 / 强度条 / 尺子时（要看的是效果，不是红色）。红色比屏上的形状旧（还没算出来）时也隐藏，拖渐变 / 圆形 / 画笔时手柄已经在表示形状；**例外：拖范围条（明暗、颜色、远近的 lo / hi / 羽化，登记表 `overlayFollowsStale`）时旧的红色保留，新的一到就直接换上（不闪、不留空帧），选区带一点延迟跟着条走；松手后保留到与最终值一致的那张到达。**
- 来源：`dapple_session_mask_preview`，输出画面坐标，长边 = 照片在屏上的设备像素（≤ 1024），一个请求在途、最新者胜、至少间隔 80 ms；返回的灰度图由 GPU 着色（`ColorFilter.matrix`：红色，不透明度 = 灰度 × 0.5），不在 Dart 里逐像素处理，绘制时不重新栅格化。

## 7. 区域芯片

- 位置：竖屏在页眉一行（标题右侧）；窄窗格在页眉第二行（原来放读数的位置）。永远不出第二层菜单。
- 一个芯片 32 dp 圆角方块，里面是该区域第一块形状的小图标；多于一块时右下角一个小 "+"；反选时图标反白；选中 = `accentSoft` 底 + `accent` 描边；关闭（`on:false`）的区域淡显。
- 放不下时芯片缩到 26 dp；16 个都在时页眉这一行才可横滑（极端情况，正常 1 – 5 个）。
- 上限：16 个区域（[+] 淡显，点按提示条"最多 16 个区域"）；每区域 8 块（"每个区域最多 8 块"）；画笔每张 8 个（"画笔最多 8 个"）；AI 蒙版每张 4 个（届时同理）。

## 8. 撤销、持久化、性能

- **撤销**：一次手势一步——拖一个手柄、画一笔、拖一次盘面 / 强度条 / 尺子、点一次取样、菜单里的一个动作、新建一个区域。
- **持久化**：`EditState.local` 随编辑存（`toJson` 多存每个区域的盘面状态 `ui`），下发引擎时只发引擎认识的键（`toWire` 的 `"local"`）。导出路径不变（引擎读 `"local"`）。复制 / 粘贴设置、同步设置 v1 不带区域（区域长在这张照片的内容上）；还原为自动结果清空区域。
- **坐标**：屏幕 → 画面（ZoomView 内，缩放 / 平移由 Flutter 的变换处理）→ 照片坐标。画面 ↔ 照片是仿射的（旋转、拉直、翻转、裁切），所以几何每变一次只调三次 `dapple_session_map_point` 取出仿射矩阵（另取一次无几何的探针得到照片宽高比，用于"长边的分数"这类半径），之后的手柄计算全在 Dart 里，拖动时不过 FFI。
- **画笔**：指针点经过平滑（指数平滑 + 最小间距 = 半径的 1/4），笔压忽略；点先进缓冲，每个 vsync 合并一次写进编辑（一帧一个 JSON，引擎测得追加 0.7 ms），笔迹本身由 Flutter 立刻画出（不等引擎）。第二根手指在笔迹提交前落下 = 这一笔作废（转为缩放）。
- **渲染**：拖手柄 / 画笔走引擎的交互帧（`beginInteraction`），松手后出精细帧；面板在拖动时不重建（同 v0.6）。

## 9. 种类登记表与 AI 区域（v0.2，2026-11-14）

`localKinds`（`lib/model/local_kinds.dart`）是一张表：`{id, 图标, 字, 小字, 引擎 kind, 摆放方式, 需要的分析任务}`。形状卡片、芯片图标、工具条、上限检查都从表里读；加一种区域 = 加一行。服务接缝 `lib/services/local_ai.dart`（`LocalAi`，测试里换成假的）。引擎侧见 pipeline-architecture.md 第 41 节。

```
[+] 的卡片：第一行形状，第二行 AI（设备能做、且分析没有排除的才出现）
┌──────────────────────────────────────┐
│  ▤      ◯      ✎      ▬      ◍      │
│ 渐变   圆形   画笔   明暗   颜色     │
│  ◉      ▣      ◎      ☁      ≋      │   ◉ 分析中：图标上一圈确定进度，再点一下取消
│ 人物   背景   点选   天空   远近     │
│                     粗略             │
└──────────────────────────────────────┘
```

- **人物**：卡片原地换成"部位"——分析（一次，服务于所有部位，之后从缓存几十毫秒）进行中是进度圈 + 取消；找到人后是小芯片：整个人、脸部皮肤、身体皮肤、头发、衣服；每张正脸再一行"脸"：眼睛、虹膜、眼白、嘴唇、眉毛、牙齿（只列出找到的）。可多选，「添加」= 一个区域，各部位的平面相加。没找到人：一句"没找到人"，没有可选的东西。
- **背景**：人物的补集，只在找到人时出现。**天空**：一下就成，卡片上小字"粗略"（经典方法，只认晴空）；没找到时提示"没找到天空"，这块从卡片上消失。**远近**（打包了深度模型才有）：工具条上一条"近 ▕━━━━━━▏ 远"的双把手带，和明暗带同一控件（lo / hi / 渐隐）；默认最近的 30 %。
- **点选**：新区域先是关着的（空的点选不会让导出去要一个不存在的平面）；在照片上点一下 = 选中那里的东西（第一下约 1 秒、之后约 0.25 秒；工具条右端一个小进度圈，照片不被挡住），再点 = 加上；工具条上 [+|−] 切换成"点一下去掉"，↶ 撤销上一下。每一下是一个撤销步。
- **合并规则不变**：AI 平面和形状一样（加一块 = 并上，减一块 = 去掉，明暗 / 颜色 = 限定）。AI 边缘不完美时的补救写在动作里：AI 区域的动作行多两格 **涂抹补充 / 涂抹擦除**（加一个相加 / 相减的画笔块并直接选中它）。
- **平面丢了**（缓存被清、换了设备）：打开局部时先自动补（磁盘缓存、否则重算，后台）；仍然缺的块，工具条上只有一个「重新分析」。导出由引擎自己补，补不了就失败而不是出一张错图。
- **内存**：系统内存紧张（`didHaveMemoryPressure`）和离开编辑器时释放模型（`dapple_ai_release(1)`）。
- 上限：AI 平面每张最多 4 块（"人物、天空、点选这类最多 4 块"），选部位时就拦住。

### 9.1 人像（v0.3）

**统一规则：默认界面是简化操作，只有点「分项」才进入细调。** 没有成排滑杆，没有新控件；不改脸型，保留皮肤纹理，默认温和（引擎第 43 节）。

```
[+] 卡片的 AI 行多一格「人像」（找到人才出现）→ 分析一次（进度同第 9 节）→
┌──────────────────────────────────────┐
│ 人像 [+][☺][…]        对比  复位  分项 │   对比：按住 = 没有任何局部区域的照片
│ ┌──┐ [肤质][眼下][油光][牙齿]            │   芯片 = 一键开关；底色 = 开；描边 = 正在调
│ │强│ [眼睛][嘴唇][补光]                  │   强度条 = 选中芯片的整套配方：下 0、中 = 推荐、上 = 上限
│ │度│ (◉1)(◉2)  ← 只有多于一张正脸时出现  │
│ └──┘                                    │
└──────────────────────────────────────┘
照片底部（肤质选中时）：[点一下祛斑] ∘ ○ ◯ ⬤
```

- **入口**：[+] 卡片里的一格「人像」（登记表一行，`aiPortrait`）。第一次点：分析人物和脸（一次，之后从缓存），然后**一步**建好温和的默认组：肤质、眼下、油光、牙齿、眼睛、嘴唇（补光默认关）。做不了的芯片直接不出现：没有正脸 → 没有眼下 / 眼睛 / 嘴唇；闭着嘴 → 没有牙齿；侧脸只剩肤质、油光、补光。
- **芯片 = 区域**：每个芯片是一个（眼睛是两个：眼白提亮、虹膜眼神，因为提亮会让棕色虹膜发灰）普通区域，id 固定（`pt-skin` …），名字 `portrait:<id>`，在区域芯片里以人脸图标出现，之后可以涂抹补充 / 擦除、删除。点关着的芯片 = 打开并选中；点开着的另一个 = 选中；再点选中的 = 去掉（提示条可撤销）。重新分析时按同一 id 更新遮罩，不会重复。
- **一根强度条**：选中芯片的整套配方在 0、推荐值、上限之间线性缩放（第 43.8 节的推荐 / 上限：磨皮 30/100、匀肤 25/60、去红 30/70、祛斑 50/100、眼下 40/80、油光 30/80、美白 30/60、眼神 25 + 饱和度 10、唇色 10/30、补光 30/60）。**不另设"人像强度"**：每个芯片都有自己的条，一根总条只会和它们打架。
- **遮罩**：肤质 / 油光 = 脸部皮肤 ∪ 身体皮肤，减去每张脸的嘴唇和牙齿（张嘴时油光会把牙齿压灰）、只有一张脸时再减去眼睛和眉毛；其余芯片用对应的面部平面（眼下 `fN:undereye`、牙齿 `fN:teeth`、眼白 `fN:sclera`、虹膜 `fN:iris`、嘴唇 `fN:lips`、补光 `fN:face`）。`retouch.face` 总是填：取自眼睛 / 虹膜平面两块的间距（引擎的分析结果暂时没有给出 iod，见报告），侧脸用脸框宽度估。
- **多张脸**：默认所有脸；有两张以上正脸时，芯片下出现一排脸的小圆图（从屏上的照片裁出），点一下 = 选中的芯片是否作用于这张脸。
- **分项**：选中芯片的几个参数，同一个性格图 + 尺子（肤质：磨皮、匀肤、去红、祛斑、纹理、祛斑灵敏度；其余一两项），夹在配方上限内。
- **点一下祛斑**：肤质的工具条上一个开关；开着时在照片上点 = 加一个祛斑点（半径按脸的大小，四档同画笔），点在已有的点上 = 去掉；每一下一个撤销步；只有开着时才画出细圈；双指照常缩放平移。
- **对比**：局部里照片上的长按属于手柄，所以页眉有一个「对比」，按住 = 不带**任何**局部区域的照片（修饰是几个芯片的总和，单看一个没有意义），对所有区域都有效。
