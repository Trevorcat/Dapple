# 折叠屏适配设计（编辑页）

版本 0.4（2026-11-14）：成像和手机同构（默认层是成像芯片、强度条和成像拖板，芯片把拖板换成成像地图，选定后回到拖板；浮球默认拖成像拖板，地图打开时才逐个换成像）；一列的自上而下顺序是直方图、六个类别、所选类别的标题行（含局部的区域芯片、成像的芯片）、强度条加拖板；标题行取自然高度，顶上留出统一的内边距，换边的细横条在直方图之上自成一带；直方图按去掉两端的最高柱定标，黑白两端堆积不再把整条压平。版本 0.3（2026-11-14）：照片上缘留出状态栏下的 6 dp；工作台两张卡等高、不留带；裁切时直方图卡不再收成一行；竖构图的一列改用 dock 的图标加文字，宽度取照片剩下的宽度（272–400 dp），照片和一列相接；书本式半开（宽窗口、横折痕）折痕下用工作台两半；裁切时单手簇让开照片四角，拖裁切框的把手时淡出；封面尺寸窗口只看、选、发布（第 9 节）。版本 0.2（2026-11-14）。取代 0.1（已作废：按屏幕分区、沿折痕拆面板、把阔折叠当翻盖式，业主否决）和探索稿 `fold-editor-study.md`。依据：业主在交互原型 `build/design-canvas/project/FoldBall.dc.html` 里确认的两种版式；设计思想见 `design-philosophy.md`；通用规则见 `guidelines.md`。实现：`app/lib/editor/fold_layout.dart`（几何）、`app/lib/screens/editor/fold_panels.dart`、`fold_cluster.dart`、`editor_page.dart`；测试：`app/test/fold_layout_test.dart` 和页面扫图的 `*-fold` 目录。

一句话：**按窗口尺寸类别和姿态排版，不按机型。** 含义一处不改：按住对比、已选中再点出操作卡、强度条的含义、分项、加减开关、系统返回一次关一层，和手机上完全一样。

## 1. 原则（业主的决定，按提出顺序）

1. 看得见的区域变大，够得着的区域变小：分开设计。一根手指必须能做完所有事，两只手更快。
2. 不假定手在下角：握持常在侧边的中段。所以单手簇的高度跟着人走（沿边拖动；拖过中线换边）。`handedness.dart` 的被动推断只是辅助，手动选过之后本次不再被它改动。
3. 照片完整显示（不裁切填满），贴着上缘；返回、撤销、保存、更多浮在照片的角上，没有单独的顶栏。
4. 横构图的照片在近方形的内屏上：照片下面的一带是**工作台**，自己就能完整操作（给另一只手或低握用）。
5. 竖构图的照片：空出来的一条在侧边、在握持拇指够得着的地方，所以没有浮球，是一列。
6. 复用，不另做（模件）：直方图、标题行、强度条、拖板、成像地图、分项、局部的卡片和开关、裁切的比例和刻度尺都是手机面板里的那一份。

## 2. 尺寸类别和姿态

| 类别 | 条件 | 版式 |
|---|---|---|
| 大近方窗口 | 短边 ≥ 600 dp，宽高比在 2:3 到 3:2 之间（书本式内屏、阔折叠内屏，横竖都算） | 按照片（裁切、旋转之后）的方向：宽 ≥ 高用**工作台**，否则用**一列** |
| 半开的横折痕 | 折痕横贯窗口，姿态为半开（翻盖式半开、书本式立着） | 照片在折痕上方，所有控件在折痕下方，折痕上不放东西（用手机的面板和 dock，铺在折痕下面的区域） |
| 高手机 / 普通手机 | 其余（翻盖式平摊是高手机；窗口短边 < 600 dp） | 现有手机版式，不变 |
| 小窗口（外屏） | 现有小窗口处理 | 不变 |

折痕和姿态读 `MediaQuery.displayFeatures`（逻辑像素，引擎已除过像素比）。只认折叠和铰链类，忽略刘海。折叠或展开时同一页面的状态不动：照片、缩放、类别、所在层、选中的区域都保留（窗口变了，几何重新算，面板按原有的动画过渡）。编辑照片的构图选“裁切”时，照片的方向按进入裁切前的算，选一个比例不会把版式翻个面。

## 3. 工作台（横构图照片，近方窗口）

```
+--------------------------------------------------+
| <                          [撤销 重做 保存 更多] |  照片完整，贴上缘
|                                       +------+   |
|                                  (100)|光线  |   |  圆环 = 强度
|                              [分项] ( ● )|颜色  |   |  浮球，分项小药丸
|                                    [•••]|成像  |   |  握把
|                                       |质地  |   |
|                                       |局部  |   |
|                                       |裁切  |   |
+---------------------+ 折痕 +---------------------+
| 直方图              |      | 强度条 |   拖板     |
| 光线  强度 100%     |      |        |            |
|               复位 分项    |        |            |
+---------------------+      +--------------------+
```

- 照片区高度 = min(窗口宽 / 照片宽高比, 窗口高 − 工作台最小高度)，最小高度 236 dp（局部的头多一行时再加），照片区至少 300 dp。照片靠上居中；窄了就两侧留舞台色，不裁。
- 工作台分左右两半，中间留缝：折痕落在缝里（缝的宽度至少 48 dp，折痕两侧各留 24 dp），任何控件不压折痕。没有竖折痕时两半之间只留 16 dp，右手一半（垫板）占约 58% 宽，两半等高（直方图卡随高度长，不留空带）；裁切时直方图那半也保持整高（缩成一行会在它下面留一条空带）。照片矮到放不下一列六个类别时，类别栏改成两列三行，六个都在屏上，不滚动。半开折叠（横折痕）时，照片占折痕以上的整块区域并居中，不留灰带。折痕横在工作台那一带时，工作台整体放到折痕下面，照片放在上面。
- 左半：直方图在上，标题行在下（类别名、读数、复位、分项）。高度不够时直方图让出来，标题行不缩。右半：强度条加完整的拖板。**分项和拖板在同一个位置互换**（和手机一样，从不同时显示）。**拖板在握持手这一侧**，左手镜像。
- 成像：和手机一样，默认层是左半标题行里的成像芯片加读数，右半是强度条加成像拖板（淡/浓、亮/暗）；点（或按住滑动）芯片，地图在拖板的位置打开（有返回箭头），选定后回到拖板；系统返回关地图。局部：先是区域类型的图块，选了之后是强度条加拖板，光线/颜色/质地开关在左半的标题下。裁切：比例和旋转、翻转的按钮加拉直刻度尺。
- **单手簇**只浮在照片上，绝不跨照片和工作台的边界：
  - 一列六个类别（竖排，贴握持一侧的边，照片太矮时这一列可以滚）；
  - 浮球（76 dp）在它旁边：按住不动 = 对比（原片），按下并向任意方向推 = 相对拖动拖板（以按下时的值为起点，110 dp 走满全程）。成像里默认推 = 拖成像拖板；只有地图打开时，推 = 在地图上按方向一步步换成像，照片实时跟随。分项里推 = 调选中的那一项。裁切里推 = 拉直。局部里，点一下浮球在“调拖板”和“移动选中的区域”之间切换（只有圆形和渐变能移动）；
  - 强度环在浮球上方：竖向拖动 = 强度条，里面是百分数；
  - 小“分项”药丸在浮球旁（分项是当前类别的细节，**不是第七个类别**）；
  - 浮球下面的握把：上下拖 = 沿边挪高度；横向拖过照片的中线再放 = 换边；
  - 空闲 3.5 秒后淡到 45%，一碰就回来。
- 返回、撤销/重做、保存、更多：浮在照片的上角，不占单独的一条。

## 4. 一列（竖构图照片，近方窗口）

```
+---------------------------+--------------+
|  <        [撤销 … 更多]   | 直方图       |
|                           | 光线 100%  分项
|         照 片             | 光线 颜色 成像
|                           | 质地 局部 裁切
|                           | 强度条 | 拖板 |
|                           | ━━ 拖柄     |
+---------------------------+--------------+
```

- 一列在握持一侧，宽度取照片（整高、完整显示）剩下的宽度，限制在 272–400 dp，所以照片和一列相接、中间不空；只有一列已到最宽时，照片才在剩余区域居中。照片贴上缘。没有浮球：空出来的位置本来就在握持拇指够得着的范围里。
- 从上到下（层级自上而下）：直方图、六个类别（第一层；两行三列，用 dock 自己的图标加文字项 `DockItem`，不带按住弹出）、所选类别的标题行（类别名、复位、分项；读数独占一行；局部的区域芯片和光线/颜色/质地开关、成像的芯片都属于标题行，在类别之下）、强度条加拖板（和分项、成像地图互换）。标题行就是手机面板的那一个，取自然高度，同一条中线。换边的办法和球的握把一样：拖栏顶的细横条到另一边（不再有整行按钮）。
- 折痕横贯这一列时（书本式内屏转了方向），列拆成上下两块，中间留出折痕的带，带里什么也没有；上块是直方图和标题行，下块是类别和拖板。

## 5. 半开

窄窗口（翻盖式）：
照片区在折痕上方，铺满那半屏的宽度，贴上缘；返回、撤销等浮在照片角上。折痕下面是手机的面板（高度占满那半屏，拖板自己吃掉多余的高度）和 dock，面板宽度不超过 600 dp 居中。一进入这种姿态，如果没有打开的类别就打开“光线”，这样控件总是在手边。

## 6. 控件始终打开（折叠版式里的返回规则）

在所有折叠版式里，控件是版式的一部分，不是一层临时的东西：

- 打开的类别是“家”：系统返回不会把它关掉；先关分项、复杂编辑器、局部的卡片，都关完之后返回离开编辑页。
- 成像的地图是成像的家，不算一层。
- 点照片的空白处不折叠任何东西，也不进沉浸模式。
- 再点一下已选中的类别：不变（手机上这会收起面板）。
- 手动选过手边（握把、栏顶的拖柄）之后，本次编辑不再让被动推断改它。选择写入设置的“手的一侧”。

## 7. 还没定的

- 工作台的浮球按住对比目前只在浮球上；是否也让握把一带响应，看实机。
- 工作台的高度在局部有多个区域时会多出一行，照片随之变小；是否改成工作台内部滚动，看实机。
- 半开的宽窗口（宽 ≥ 600 dp，折痕下高度够）已用工作台两半，照片上方有单手簇；窄的仍是手机面板。
- 裁切目前是比例按钮加拉直刻度尺，应用里还没有可拖的裁切框和把手；单手簇为将来的把手做了两件事：拖把手时淡出（`FoldCluster.hidden`），裁切里不压照片四角（56 dp 见方）。边中点的把手在握持侧会被类别栏压住，裁切框做出来时再定。
- 单手簇里的类别列在照片矮于约 370 dp 时要滚动。
- 浮球推动的灵敏度（110 dp 走满全程）、成像里按方向换成像的步长、移动区域的倍率（2.6 倍）都是估的，要在实机上调。
- 没有在实机上验证：所有尺寸都是用窗口大小和模拟的折痕在主机上渲染出来的。

## 9. 封面尺寸窗口（只看、选、发布）

规则按窗口大小，不按机型：宽 < 480 dp 且高 < 520 dp（外屏、小窗口）算封面尺寸。这里用来看、选、分享，不用来修：

- 首页是照片格子（手机版式）；点一张进入“编辑页”，但此时编辑页是一个查看器：照片整张显示，贴上缘；角上是返回和“发布”，不是当前最新的一张时多一个“最新”；
- 照片下面一条：上一张、位置（几 / 共几）、一行字“窗口太小，展开设备后再修图”、下一张；左右滑也换一张；
- 相机传来的最新一张：停在最新一张时，新的一张到了，查看器跟着换过去；
- 没有 dock、面板、局部的手柄和裁切网格；已有的编辑一点不动。窗口变大（展开）后，同一页面回到编辑版式，照片、类别、层都在（状态在同一个页面里，只是不画）。

## 8. 已作废的版本

0.1 版（2026-11-14）把折叠屏当成按屏幕分区的版式，业主否决，不再采用；平台的折叠和铰链机制（`displayFeatures` 的含义）以本文第 2 节为准。
