## 1. 原则（视觉层）

1. 照片是内容，界面是功能层。界面中性，不抢颜色。
2. 强调色只有一个（蓝），只用于：主操作、选中态、已改动标记、进度。
3. 亮色优先，随系统切暗。**无应用内主题开关。** 不用壁纸取色（不用 Material 动态取色）。
4. 玻璃（模糊半透明）只用于悬浮的导航 / 选择栏，不叠玻璃，不用于内容层。照片上的叠加物（徽标、计数、对比按钮）用实底半透明黑。
5. 照片周围用中性灰舞台，聚焦时更接近 18% 灰，不用纯白 / 纯黑。
6. 状态不只靠颜色：必须同时有形状、图标或文字。
7. Apple HIG 为主（层级、克制、大标题、胶囊标签栏、系统分享）；Android 用 Material 3 形状与行为（48 dp、导航栏、Snackbar、预测性返回）。

### 2.5 高对比变体【开放】

HIG 要求每个自定义颜色提供亮、暗、高对比变体。原型未提供高对比值。需为 `text2`、`accent`、`sep`、`outline`、`track` 定义增强版，并在系统开启“增加对比度”时切换。

## 3. 字体

- iOS：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Noto Sans SC', 'Helvetica Neue'`（Flutter：系统字体）。
- Android：`Roboto, 'Noto Sans SC', 'PingFang SC'`。
- 数字一律等宽数字（`tabular-nums`）：数值、计数、百分比、时间。
- 避免 Light / Thin。iOS 只用 400 / 600 / 700；Android 用 400 / 500（导航选中标签 700）。
- 不使用 10 px 及以下；最小 11。
- 支持系统字号放大至少 200% 且不截断；放大时图标同步放大。

## 6. 控件高度与点击区

| 控件 | iOS | Android |
|---|---|---|
| 图标按钮 | 44 | 48 |
| 通用控件（按钮、行、菜单项） | 44 | 48 |
| 主按钮（页底 CTA） | 52 | 52 |
| 引导主按钮 | 52 | 52 |
| 顶栏 | 状态栏 + 48 | 状态栏 + 64（首页）/ 48（编辑） |
| 完成按钮 | 44（文本） | 40（实心）——点击区外延到 48 |
| 分组标签（编辑） | 48，最小宽 60 | 同 |
| 滑杆行 | ≥44 | ≥48 |
| 复位按钮 | 44×44 | 48×48（至少 44） |
| 列表行 | 52–68 | 56–68 |
| 连接卡 | 最小 64 | 同 |
| 连接卡动作 / chip | 视觉 36 | 视觉 32 |
| 分段控件 | 40（命中 ≥44） | 40（命中 ≥48）【缺陷】 |
| 抓手 | 24 高，全宽命中 | 同 |
| 缩略图星标 | 视觉 26，命中 44 | 同 |
| 序号圆 / 勾选圆 | 视觉 26 / 20，命中 = 整格 | 同 |

- 点击区下限：iOS 44×44 pt，Android 48×48 dp。视觉小于下限的控件必须把命中区扩到下限（`padding` 或 `minimumSize`）。
- 统一用 `HitBox`（`widgets/controls.dart`）：视觉尺寸不变，外面一层至少 48×48 的命中框，放在 `GestureDetector`（opaque）里；命中框不能比父级大，所以放它的行本身至少 48 高（编辑器页眉一行 48）。相邻控件的命中框可以相接，不重叠。
- **拥挤时换行，不缩小**：一行放不下（区域芯片、照片上的工具条、动作卡、裁切比例）就换到下一行，或让旁边的读数 / 文字让位；不把控件缩到命中区以下，也不用 `FittedBox` 缩小可点的东西（只允许缩小不可点的读数）。
- 【缺陷】原型中的连接卡动作（36）、首页“选择”胶囊（36）、分段控件（40）、大屏 Android 控件（40）低于下限；实现时扩大命中区。
- 带边框控件周围约 12 间距，无边框约 24 间距（HIG）。

## 12. 无障碍

### 12.1 目标与对比
- 点击区 ≥ 44 pt（iOS）/ 48 dp（Android）；跨平台统一下限可取 48。
- 文本对比 ≥ 4.5:1（≤17 pt 或非粗体），大字（≥18 pt 或 14 pt 粗体）≥ 3:1；自定义小字追求 7:1；非文字元素（图标、边框、状态）≥ 3:1。见 2.4 的计算值与缺陷。
- 玻璃与照片之上、亮暗两种外观下都检查。
- 状态不只靠颜色：已选 = 对勾 + 序号；已调整 = 圆点 + 名称加粗 + aria；传输中断 = 琥珀 + 文字标签；预览 = 空心点 + aria。

### 12.2 焦点与键盘
- `:focus-visible`：3 px `accent` 描边，偏移 2；Flutter：`FocusTraversalGroup` + 自定义焦点装饰。
- 对话框：焦点移入、Tab 循环、Esc 关闭、关闭后归还给触发元素。
- 自定义手势都有等价操作：长按多选 ↔ “选择”；片段条拖动 ↔ 方向键（2%，Shift 移封面）；**编辑器（v0.5）见 15.5**：参数相对拖动 ↔ 可调整语义节点；长按原片 ↔ 照片节点的语义动作 / 大屏键盘按住 Enter 或空格（界面上不放对比按钮，负责人决定）；对比进行中，照片上缘的瞬时读数胶囊写“原片”（局部里写“无局部调整”），这是对比的可见状态（15.2.5）。（原“按住对比 ↔ 对比开关”“抓手”“调色盘 ↔ 方向键”作废。）

### 12.3 角色与语义

| 元件 | 角色 / 属性 |
|---|---|
| 单选组（默认成像、明暗目标、通道、色范围、区域、比例、投影、分段、预设） | `radiogroup` / `radio` + `aria-checked` |
| 开关 | `switch` + `aria-checked` |
| 复选（缩略图选择、同步项、来源） | `checkbox` + `aria-checked` |
| 筛选 chip、对比开关、基准帧星 | 按钮 + `aria-pressed`（筛选组**不是** tablist） |
| 标签（大屏检查器） | `tablist` / `tab` / `tabpanel`；分组头 `aria-expanded` / `aria-controls` |
| 当前导航项 | `aria-current=page`；胶片条当前项 `aria-current=true` |
| 滑杆（仅设置页 / 创作工具） | 原生 range（Flutter `Semantics(slider)`）+ `aria-valuetext` |
| 编辑器参数行（v0.5） | 可调整节点：`increasedValue / decreasedValue / onIncrease / onDecrease` + 自定义动作（大步、复位到自动、输入数值）；值文本 = 显示文本，自动位附加“，自动” |

| 菜单 | `menu` / `menuitem` |
| 直方图 | `img` + `aria-label`“直方图，{明亮 · 柔和}” |
| 装饰 SVG | `aria-hidden` |

### 12.4 动态内容
- 提示条：常驻 `role=status` `aria-live=polite` 区域（内容变化即播报）；带动作的提示 8 秒，不得在读屏用户操作前消失【待验】。
- 后台任务条：`role=status`。
- 状态变化（到达中 → 处理中 → 已处理）不播报逐张；只播报连接卡状态行变化。

### 12.6 字号与缩放
支持系统字号放大 ≥200% 不截断；图标随字号放大；动效尊重系统“减少动态效果”。所有自定义图标需有文字标签。
- 编辑器页眉：字号 ≥ 130 % 时标题（和读数）一行、按钮另起一行，按钮里的字不缩小（`kHeaderWrapScale`）；面板高度把这一行算进去。只有一个按钮的页眉（裁切）不换行。
- 格子类控件（人像芯片、动作卡、种类卡）在大字号或矮面板里先缩图标、不缩字；字永远不小于 11。

## 13. 文案规范

### 13.1 语气
- 简洁、直接、平等。说结果与动作，不解释，不教学，不夸，不道歉。
- 不写说明句、提示句；不写“请”；不用感叹号；不用 emoji。
- 一个界面元素只用一个词；动词开头给动作，名词给状态。
- 失败文案 = 发生了什么 + 下一步按钮，不写原因猜测。
- 不用学术词（影调、动态范围、色阶分布……）；专业名只作为小号次要标注，且仅限“高长调”类。

### 13.2 格式
| 规则 | 示例 |
|---|---|
| 数字与汉字之间、英文与汉字之间加半角空格 | 已选 3 张；Sony α7R V · 已连接 |
| 量词前的数字不用全角 | 12 张、9 张 |
| 并列信息用“ · ”（间隔点，两侧空格） | 均衡 · 强烈；原比例 · 九宫格 |
| 命名对象用「 」 | 已存入相册「Dapple」；新照片默认使用「暖阳」 |
| 会再弹出界面的操作加“…” | 同步设置…、分享…、从全部照片中选…、添加相机… |
| 单位 | 长边 2560 px；+0.50 EV（负号用 −U+2212）；度用 °；百分比用 % |
| 时间 | 14:20；0:14 |
| 提示条不带句号；标题不带句号；问句保留问号 | 还原为自动结果？ |
| 对象计数放主语之后 | 合成 3 张；发布 5 张 |

### 13.3 平台用词
- iOS 只说“实况照片”；Android 只说“动态照片”；同一平台不混写。
- 术语以需求第 5 节为准（风格、明暗、色偏、分级、处理、原片、原比例、同步设置）。
- **名词（U8）**：**成像** = 照片的底（标准、三种现代成像、各支胶片）——编辑器坞项、面板标题、首页第二个标签都叫“成像”，成像页写“新照片默认成像”；**胶片** 只是成像里的一组（胶片地图里的胶卷盒、选中胶片时按钮上的代号）；**风格** = 叠在成像之上的颜色风格（颜色盘上的点）；风格的名字不与成像的组名重名（原“胶片”风格改名“胶片感”）。**区域** = 一个可调的地方；**块** = 区域里的一个形状（渐变、圆形、画笔、明暗、颜色、AI 平面都按“块”计）；“点”只用于祛斑点；“部位”只出现在人物卡里；不出现蒙版、遮罩、组件、图层。上限文案：最多 16 个区域；每个区域最多 8 块；画笔最多 8 块；人物、天空、点选最多 12 块；最多 N 个祛斑点。

## 15. 编辑器交互 v2：原则与组件（v0.5，2026-11-12；15.1 已按 v0.6 重写）

完整行为、数值、手势仲裁表与版式见 `requirements.md` 4.15；本节是设计层的原则与组件规格。

### 15.1 交互原则（v0.6，2026-11-12 重写）

v0.5 的原则 1（相对映射）、2（速度增益与精细带）、3（起手锁轴）、6（手指在窗外任何位置操作）、10（无滑杆外观、尺子只读）被负责人的真机试用**推翻**。原因都是同一条：**手指和眼睛分离**——在照片上相对拖动改值，看不到自己在碰什么，也不知道当前在哪个参数；一条横滑的芯片条堆了十几个参数，层级不清。新原则如下，旧原则中保留的（触感只在地标、交互中不重排、自动是起点、物理动效）并入其中。

1. **所见即所触。** 绝对映射：光标就在手指下面，手指落在哪里，值就是哪里；盘面只在画出来的范围内操作；盘面上不画照片，照片上不做调节手势（照片只有缩放、平移、按住对比）。**对比全 App 只有一种（U4）**：在照片上按住 380 ms 不动 = 看对比，松手恢复；界面上不放「对比」按钮。局部里起点在手柄上的按住归手柄，起点不在手柄上且不动的按住 = 看“没有任何区域”的照片（瞬时读数写“无局部调整”）；画笔移动 8 dp 后才落墨，点选 / 祛斑的“点一下”在抬手时生效，变成按住的不加点。取代“相对映射，手指落在哪里无关”：相对映射省了小目标，却让手指和值脱节，试用时连“现在改的是什么”都读不出来；绝对映射的小目标问题用占满整块区域的大盘面解决。
2. **尺子跟手。** 刻度带跟着手指走（向右拖，刻度向右移，值变小），一个像素对一个像素。取代“指针固定、手指向右值增大”：试用时它像滑杆而不是尺子，内容跟手才符合直觉。尺子随之不再是只读装饰，而是可拖动的控件；点数值键入；档位触感在自动位和范围两端。
3. **按意图分层，不按参数罗列。** 三层：第 1 层照片和五个分类；第 2 层一块盘面加一条强度竖条；第 3 层“分项”（性格图加一把尺子）。取代“一条芯片条放全部参数”：参数有十几个，意图只有两个——“要多少”和“往哪边”。复杂的非标量编辑器（曲线、分色、分级、相纸）作为第 3 层的附加入口，不占前两层。
4. **一个元素三份工作。** 坞里的小方块是入口、状态和读数：方块里的点是盘面位置，旁边的细条是强度，没有第二个徽标。按住它盘面就弹出来，拖动相对按下时的值，松手收回，照片保持全尺寸。
5. **强度加方向。** 每个分类都是“一根竖条 = 强度”加“一块盘面 = 两个方向（暗亮、反差，冷暖、淡浓，淡浓、暗亮，柔锐、干净颗粒）”。盘面的每个位置通过配方（纯函数 pad(x, y, 强度) → 一组参数值）同时设定多个底层参数；底层参数仍是引擎的唯一真值。
   **强度条只有一种意思（U1）**：最下 = 没效果；**中线 = Dapple 推荐的量，读作 100 %**；最上 = 这个控件能给的最多，读数是它相对推荐量的真实百分比（不是一律 200 %）。吸附中线有触感。凡有强度条的面板，页眉读数位置都显示“强度 N %”，语义值与读数是同一个数（`stripPercent` / `localStripPercent`）。各处的“推荐”与“最多”：光线 = 设置里的默认明暗强度（缺省 60）→ 明暗强度 100（167 %）；颜色 = 风格强度 100 → 上半再加鲜艳度 / 饱和度（200 %）；成像 = 完整的胶片效果 → 颗粒、光晕到参数上限并抬黑位（200 %）；质地 = 默认锐化与降噪 → 1.8 倍（180 %）；局部区域 = 引擎强度 100 → 配方加倍（200 %）；人像芯片 = 配方推荐值 → 配方上限（读作第一项的倍数，如肤质 333 %、牙齿 200 %）。改读数不改映射：已存的编辑看起来完全一样。
6. **盘面自己不讲道理，图标讲。** 盘面是一整块安静的底：只在颜色本身能解释的地方用渐变，细点阵，四条边中点各一个线条图标（白色细阴影，深浅底都读得出），盘面上没有文字。图标六对全 App 通用（月/日、弱/强对比、蓝点/橙点、空心/实心水滴、波/锯齿、空/点方块）。
7. **交互进行中不重排。** 拖动期间不移动、不缩放、不替换控件；面板高度在一个分类内恒定，换层不换高度；惯用手、布局切换只在抬手后的空闲期。
8. **触感只在地标。** 自动位吸附（盘面中心、强度条中线）、尺子的自动位和两端、预设点；连续改值静音。
9. **自动是起点，永远可回到它。** 盘面中心有一个小圆环，轻微吸附；分类复位；每项尺子上有单项复位；不用确认框，用撤销。
10. **物理动效，可打断。** 跟手 → 继承速度 → 弹簧收敛；面板、照片区域、坞三个矩形一起插值；胶片地图的放大 260 ms 缓动，可随时松手打断。

#### 15.2.8 页眉（U6）
所有面板层同一个页眉：`[‹] 标题 · 读数或副标题 ……（复位）· 主动作`（`PanelHeader`）。
- 标题永远是坞项名（光线、颜色、成像、质地、局部、裁切），不变成“人像”“加一块”“曲线”；这一层是什么写在副标题（新区域、加一块、减一块、人物、区域 1、肤质、曲线、选成像…）。
- 进入任何下一层（分项、复杂编辑器、成像地图、局部的卡片）后标题左侧出现 ‹，按 ‹ 或系统返回回到上一层；返回永远在左边，不在按钮组里。
- 有强度条的层，副标题位置就是读数“强度 N %”（U1）；成像层在读数前放当前成像按钮（`N400C ⌄` / `选成像 ⌄`，点开地图）。
- 右端最多 3 个按钮，最后一个是本层的主动作：第 2 层 = 分项；部位卡 = 加上 / 减去；成像地图 = 无（选了东西时才有）；分项与复杂编辑器只有复位。复位未改动时隐藏但占位。
- 一侧窄窗格里副标题 / 读数在第二行；局部的区域芯片永远在页眉下自己的一行（两种布局同一位置）。字号 ≥ 130 % 时按钮另起一行（12.6）。

#### 15.2.9 对象上的动作（U3）
点未选中的芯片 = 选中；**再点已选中的芯片 = 打开它的动作卡**（区域芯片、人像芯片同一规则；选中的芯片右下带 ⌄ 作可见入口）。破坏性动作只在动作卡里：区域 = 删除，人像芯片 = 关掉，人像组（页眉的人像芯片）= 删除；执行后提示条带「撤销」，不用确认框。点芯片从不删除或关掉任何东西。

#### 15.2.10 照片上的加 / 减（U2）
在照片上添加或去掉的工具（画笔、点选、点一下祛斑）一律在工具条左端用同一个 [+|−] 分段（`AddRemoveSwitch`），默认 +；− 时画笔擦除、点选去掉、点在祛斑点上删除它。不用开关图标，不靠“点在已有处去掉”，动作卡里不放“涂抹补充 / 擦除”（要修 AI 区域：加一块… / 减一块… → 画笔）。每一下 / 每一笔是一个撤销步，由顶栏撤销收回，工具条不另放撤销。

### 15.3 动效（物理弹簧）

| 档 | 时长 | 位移弹簧（k / c，mass 1） | 透明度（临界阻尼） | 用于 |
|---|---|---|---|---|
| 小 | 150 ms | 1100 / 40（ζ 0.60） | 1100 / 66 | 读数淡入淡出、高亮条、自动位闪亮、药丸 ⇄ 一行读数 |
| 中 | 200 ms | 600 / 30（ζ 0.61） | 600 / 49 | 窗口展开 / 收起、窗内内容替换、近距吸附（≤ 200 dp） |
| 大 | 350 ms | 200 / 17（ζ 0.60；HarmonyOS 组件移动示例刚度 200 / 阻尼 17） | 200 / 28 | 惯用手换边、远距吸附、翻页收敛、窗口类别 / 姿态切换、照片避让位移 |

- 跟手 1:1（无动画）；离手以手指速度为初速度；落点用 `decelerationRate 0.99` 投影（位置 + 速度 × 0.099 s）；越界用橡皮筋。
- 可打断：新输入接管时保持位置与速度，目标改变后重启弹簧。
- 减少动态效果：位移弹簧 → 150 ms 透明度渐变。
- 取代第 9 节中“面板高度 0.2 s ease”“按住对比 220 ms”。

### 15.4 触感（仅地标）

| 事件 | Android | iOS（后续） |
|---|---|---|
| 吸附到自动位、复位完成 | API 34+：`SEGMENT_TICK`；更低：`CLOCK_TICK` | `UIImpactFeedbackGenerator(.light)`，intensity 0.7 |
| 离散换档、竖拖换参数、九格换格 | API 34+：`SEGMENT_FREQUENT_TICK`；更低：`CLOCK_TICK` | `UISelectionFeedbackGenerator` |
| 到达范围端点 | API 30+：`CONFIRM`；更低：`LONG_PRESS` | `UIImpactFeedbackGenerator(.rigid)` |
| 其余 | 静音 | 静音 |

- 经 `View.performHapticFeedback`（平台通道）；遵守系统触摸反馈；应用内可关；两次间隔 ≥ 40 ms；吸附捕获窗口 ±1.5 %（精细 ±0.5 %，极细关闭）。
- 触感被关闭时，吸附、端点仍有视觉对应（标记闪亮、读数顶住）。

### 15.5 无障碍补充
- 编辑器参数行 = 可调整节点；自定义动作：大步增 / 减、复位到自动、输入数值；2D 控件拆成可调整子节点（调色盘：冷暖、浓淡；分级：色相、饱和度；曲线：每点一个）；九格 = 9 个单选项。
- 手势等价：长按看原片 → 照片的语义动作；窗口拖动 → “移到左 / 右 / 下”；双击缩放 → “放大 / 适合”。
- 触摸探索开启时，窗外单指拖动用于探索，不改值。
- 点击区下限见第 6 节；窗口、读数的文字对比按 12.1 在照片之上检查（读数是实底，窗口不透明，对比可控）。

### 15.6 安全区与系统手势
- 所有 inset、系统手势区、底部强制手势区、刘海、铰链在**运行时**读取，不写死数值（`MediaQuery.viewPadding`、`systemGestureInsets`、`displayFeatures`；需要时平台通道取 `WindowInsets`）。
- 起点落在系统手势区的触摸不进入编辑手势；本应用不声明手势排除区，控件内缩：窗口边距 = max(12, 该侧手势 inset)，坞底距 = 底 inset + 8。
- 铰链带内不放可操作控件；桌面姿态下照片在铰链之上、窗口 / 坞在铰链之下，窗口外的可操作内容距铰链 ≥ 40、照片距铰链 ≥ 16（HarmonyOS 悬停规范数值，起点【待验】）。

### 15.7 提示条位置
编辑页提示条底边 = 分类坞顶 + 12（浮窗在惯用手侧时水平居中，不压窗）；沉浸时 = 底 inset + 12。（取代 10.9 中“面板高度 + 12”。）

### 15.8 已验证的做法（2026-11 审计 F 节，写成规则）

1. **空状态即第一步**：一个分类里还什么都没有时，面板身体直接是第一步要用的卡（局部 = 形状卡），不放说明句、不放灰掉的控件。
2. **卡片原地替换身体、做完自己关闭**：选种类、选部位、区域的动作都替换面板身体，不叠第二层菜单；页眉给“返回”。
3. **登记表驱动**：同一类东西（区域种类）由一张表生成卡片、芯片、工具条与上限检查（`model/local_kinds.dart`）；新增一种只加一行，界面自然一致。
4. **做不了的就不出现**：按照片内容给选项（没有正脸就没有眼下 / 眼睛；没找到天空，天空格消失），不显示点了也没用的入口；没做完的功能不留入口（不放“待实现”）。
5. **复位隐藏但占位**：未改动时复位按钮不可见但占位，页眉不跳（同 10.4）。
6. **拖动中面板不重建、一个手势一个撤销步**：拖盘面 / 强度条 / 尺子 / 手柄时只重绘光标层、强度条、坞字形与读数；按下到抬起是一个撤销步。
7. **侧窗格把芯片放第二行**：窄的侧窗格里，页眉第一行是标题与按钮，芯片（区域芯片、复杂编辑器入口）在第二行，各自保持 48 dp 命中；放不下再换行。
8. **编辑辅助不进导出**：照片上的手柄、红色区域范围只是编辑辅助：离开局部、导出或分享进行中都不显示；导出由引擎按参数渲染，从不合成界面图层。
