# Dapple 设计指南（Design System）

版本 0.5（2026-11-12）。v0.5 新增第 15 节“编辑器交互 v2：原则与组件”（负责人已批准），并把与之冲突的旧条目标为【已被第 15 节取代】（编辑底部面板、滑杆在编辑器内的用法、面板档位动效、滑杆触感、大屏编辑布局、对比 220 ms 等）。其余数值来自原型 `design/prototype/project/Main.dc.html`（手机）与 `Large.dc.html`（大屏）；与审查冲突处按 `design/reviews/2026-11-11-prototype-review.md` 的裁决。功能与屏幕见 `requirements.md`。

标记：【已被第 15 节取代】旧条目作废，仅作历史；【缺陷】原型内部矛盾，正文给出规定做法；【开放】待决策；【待验】待真机 / 测试。长度单位 dp（Android）/ pt（iOS）。

---

## 1. 原则（视觉层）

1. 照片是内容，界面是功能层。界面中性，不抢颜色。
2. 强调色只有一个（蓝），只用于：主操作、选中态、已改动标记、进度。
3. 亮色优先，随系统切暗。**无应用内主题开关。** 不用壁纸取色（不用 Material 动态取色）。
4. 玻璃（模糊半透明）只用于悬浮的导航 / 选择栏，不叠玻璃，不用于内容层。照片上的叠加物（徽标、计数、对比按钮）用实底半透明黑。
5. 照片周围用中性灰舞台，聚焦时更接近 18% 灰，不用纯白 / 纯黑。
6. 状态不只靠颜色：必须同时有形状、图标或文字。
7. Apple HIG 为主（层级、克制、大标题、胶囊标签栏、系统分享）；Android 用 Material 3 形状与行为（48 dp、导航栏、Snackbar、预测性返回）。

### 2.5 高对比变体【开放】

HIG 要求每个自定义颜色提供亮、暗、高对比变体。原型未提供高对比值。需为 `text2`、`accent`、`sep`、`outline`、`track` 定义增强版，并在系统开启“增加对比度”时切换。

## 3. 字体

- iOS：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Noto Sans SC', 'Helvetica Neue'`（Flutter：系统字体）。
- Android：`Roboto, 'Noto Sans SC', 'PingFang SC'`。
- 数字一律等宽数字（`tabular-nums`）：数值、计数、百分比、时间。
- 避免 Light / Thin。iOS 只用 400 / 600 / 700；Android 用 400 / 500（导航选中标签 700）。
- 不使用 10 px 及以下；最小 11。
- 支持系统字号放大至少 200% 且不截断；放大时图标同步放大。

## 8. 图标

- 24×24 画布，线性，描边 2（标签条 20 px 使用 1.9），圆头圆角，`currentColor`。Android 导航栏选中时填充（风格图标填充透明度 0.45）。

## 12. 无障碍

### 12.1 目标与对比
- 点击区 ≥ 44 pt（iOS）/ 48 dp（Android）；跨平台统一下限可取 48。
- 文本对比 ≥ 4.5:1（≤17 pt 或非粗体），大字（≥18 pt 或 14 pt 粗体）≥ 3:1；自定义小字追求 7:1；非文字元素（图标、边框、状态）≥ 3:1。见 2.4 的计算值与缺陷。
- 玻璃与照片之上、亮暗两种外观下都检查。
- 状态不只靠颜色：已选 = 对勾 + 序号；已调整 = 圆点 + 名称加粗 + aria；传输中断 = 琥珀 + 文字标签；预览 = 空心点 + aria。

### 12.2 焦点与键盘
- `:focus-visible`：3 px `accent` 描边，偏移 2；Flutter：`FocusTraversalGroup` + 自定义焦点装饰。
- 对话框：焦点移入、Tab 循环、Esc 关闭、关闭后归还给触发元素。
- 自定义手势都有等价操作：长按多选 ↔ “选择”；片段条拖动 ↔ 方向键（2%，Shift 移封面）；**编辑器（v0.5）见 15.5**：参数相对拖动 ↔ 可调整语义节点；长按原片 ↔ 照片节点的语义动作 / 大屏键盘按住 Enter 或空格（界面上不放对比按钮，负责人决定）。（原“按住对比 ↔ 对比开关”“抓手”“调色盘 ↔ 方向键”作废。）

### 12.3 角色与语义

| 元件 | 角色 / 属性 |
|---|---|
| 单选组（默认风格、明暗目标、通道、色范围、区域、比例、投影、分段、预设） | `radiogroup` / `radio` + `aria-checked` |
| 开关 | `switch` + `aria-checked` |
| 复选（缩略图选择、同步项、来源） | `checkbox` + `aria-checked` |

### 13.1 语气
- 简洁、直接、平等。说结果与动作，不解释，不教学，不夸，不道歉。

## 15. 编辑器交互 v2：原则与组件（v0.5，2026-11-12；15.1 已按 v0.6 重写）

完整行为、数值、手势仲裁表与版式见 `requirements.md` 4.15；本节是设计层的原则与组件规格。

### 15.1 交互原则（v0.6，2026-11-12 重写）

v0.5 的原则 1（相对映射）、2（速度增益与精细带）、3（起手锁轴）、6（手指在窗外任何位置操作）、10（无滑杆外观、尺子只读）被负责人的真机试用**推翻**。原因都是同一条：**手指和眼睛分离**——在照片上相对拖动改值，看不到自己在碰什么，也不知道当前在哪个参数；一条横滑的芯片条堆了十几个参数，层级不清。新原则如下，旧原则中保留的（触感只在地标、交互中不重排、自动是起点、物理动效）并入其中。

1. **所见即所触。** 绝对映射：光标就在手指下面，手指落在哪里，值就是哪里；盘面只在画出来的范围内操作；盘面上不画照片，照片上不做调节手势（照片只有缩放、平移、按住对比）。取代“相对映射，手指落在哪里无关”：相对映射省了小目标，却让手指和值脱节，试用时连“现在改的是什么”都读不出来；绝对映射的小目标问题用占满整块区域的大盘面解决。
2. **尺子跟手。** 刻度带跟着手指走（向右拖，刻度向右移，值变小），一个像素对一个像素。取代“指针固定、手指向右值增大”：试用时它像滑杆而不是尺子，内容跟手才符合直觉。尺子随之不再是只读装饰，而是可拖动的控件；点数值键入；档位触感在自动位和范围两端。
3. **按意图分层，不按参数罗列。** 三层：第 1 层照片和五个分类；第 2 层一块盘面加一条强度竖条；第 3 层“分项”（性格图加一把尺子）。取代“一条芯片条放全部参数”：参数有十几个，意图只有两个——“要多少”和“往哪边”。复杂的非标量编辑器（曲线、分色、分级、相纸）作为第 3 层的附加入口，不占前两层。
4. **一个元素三份工作。** 坞里的小方块是入口、状态和读数：方块里的点是盘面位置，旁边的细条是强度，没有第二个徽标。按住它盘面就弹出来，拖动相对按下时的值，松手收回，照片保持全尺寸。
5. **强度加方向。** 每个分类都是“一根竖条 = 强度（最下 0 = 没效果，中间 100 %，往上更重）”加“一块盘面 = 两个方向（暗亮、反差，冷暖、淡浓，淡浓、暗亮，柔锐、干净颗粒）”。盘面的每个位置通过配方（纯函数 pad(x, y, 强度) → 一组参数值）同时设定多个底层参数；底层参数仍是引擎的唯一真值。
6. **盘面自己不讲道理，图标讲。** 盘面是一整块安静的底：只在颜色本身能解释的地方用渐变，细点阵，四条边中点各一个线条图标（白色细阴影，深浅底都读得出），盘面上没有文字。图标六对全 App 通用（月/日、弱/强对比、蓝点/橙点、空心/实心水滴、波/锯齿、空/点方块）。
7. **交互进行中不重排。** 拖动期间不移动、不缩放、不替换控件；面板高度在一个分类内恒定，换层不换高度；惯用手、布局切换只在抬手后的空闲期。
8. **触感只在地标。** 自动位吸附（盘面中心、强度条中线）、尺子的自动位和两端、预设点；连续改值静音。
9. **自动是起点，永远可回到它。** 盘面中心有一个小圆环，轻微吸附；分类复位；每项尺子上有单项复位；不用确认框，用撤销。
10. **物理动效，可打断。** 跟手 → 继承速度 → 弹簧收敛；面板、照片区域、坞三个矩形一起插值；胶片地图的放大 260 ms 缓动，可随时松手打断。

### 15.3 动效（物理弹簧）

| 档 | 时长 | 位移弹簧（k / c，mass 1） | 透明度（临界阻尼） | 用于 |
|---|---|---|---|---|
| 小 | 150 ms | 1100 / 40（ζ 0.60） | 1100 / 66 | 读数淡入淡出、高亮条、自动位闪亮、药丸 ⇄ 一行读数 |
| 中 | 200 ms | 600 / 30（ζ 0.61） | 600 / 49 | 窗口展开 / 收起、窗内内容替换、近距吸附（≤ 200 dp） |
| 大 | 350 ms | 200 / 17（ζ 0.60；HarmonyOS 组件移动示例刚度 200 / 阻尼 17） | 200 / 28 | 惯用手换边、远距吸附、翻页收敛、窗口类别 / 姿态切换、照片避让位移 |

- 跟手 1:1（无动画）；离手以手指速度为初速度；落点用 `decelerationRate 0.99` 投影（位置 + 速度 × 0.099 s）；越界用橡皮筋。
- 可打断：新输入接管时保持位置与速度，目标改变后重启弹簧。
- 减少动态效果：位移弹簧 → 150 ms 透明度渐变。
- 取代第 9 节中“面板高度 0.2 s ease”“按住对比 220 ms”。

### 15.4 触感（仅地标）

| 事件 | Android | iOS（后续） |
|---|---|---|
| 吸附到自动位、复位完成 | API 34+：`SEGMENT_TICK`；更低：`CLOCK_TICK` | `UIImpactFeedbackGenerator(.light)`，intensity 0.7 |
| 离散换档、竖拖换参数、九格换格 | API 34+：`SEGMENT_FREQUENT_TICK`；更低：`CLOCK_TICK` | `UISelectionFeedbackGenerator` |

- 经 `View.performHapticFeedback`（平台通道）；遵守系统触摸反馈；应用内可关；两次间隔 ≥ 40 ms；吸附捕获窗口 ±1.5 %（精细 ±0.5 %，极细关闭）。
- 触感被关闭时，吸附、端点仍有视觉对应（标记闪亮、读数顶住）。

### 15.5 无障碍补充
- 编辑器参数行 = 可调整节点；自定义动作：大步增 / 减、复位到自动、输入数值；2D 控件拆成可调整子节点（调色盘：冷暖、浓淡；分级：色相、饱和度；曲线：每点一个）；九格 = 9 个单选项。
- 手势等价：长按看原片 → 照片的语义动作；窗口拖动 → “移到左 / 右 / 下”；双击缩放 → “放大 / 适合”。
- 触摸探索开启时，窗外单指拖动用于探索，不改值。
- 点击区下限见第 6 节；窗口、读数的文字对比按 12.1 在照片之上检查（读数是实底，窗口不透明，对比可控）。

### 15.6 安全区与系统手势
- 所有 inset、系统手势区、底部强制手势区、刘海、铰链在**运行时**读取，不写死数值（`MediaQuery.viewPadding`、`systemGestureInsets`、`displayFeatures`；需要时平台通道取 `WindowInsets`）。
- 起点落在系统手势区的触摸不进入编辑手势；本应用不声明手势排除区，控件内缩：窗口边距 = max(12, 该侧手势 inset)，坞底距 = 底 inset + 8。
- 铰链带内不放可操作控件；桌面姿态下照片在铰链之上、窗口 / 坞在铰链之下，窗口外的可操作内容距铰链 ≥ 40、照片距铰链 ≥ 16（HarmonyOS 悬停规范数值，起点【待验】）。

### 15.7 提示条位置
编辑页提示条底边 = 分类坞顶 + 12（浮窗在惯用手侧时水平居中，不压窗）；沉浸时 = 底 inset + 12。（取代 10.9 中“面板高度 + 12”。）
